# 動画を組み立てる

依頼書のとおりに組み立てて検品するだけで、構成には手を加えない（依頼書は人が確認した単位）。

## 最初に確定すること

- 入力: 人の確認が済んだ編集依頼書（storyboard の成果物）、素材、選んだツール（video-production の `route.md`）。依頼書が無いときは先に storyboard で作る
- 使うツールは、その環境で実際に動くものだけ
  - ffmpeg / ffprobe: 尺取り、検品、字幕の焼き込み、静止画に動きを付けてつなぐ
  - HTML → MP4 のレンダラー（HyperFrames など）: 文字と図が主役の動画。公式の手順に従う
  - Palmier Pro（Mac のみ。MCP でつないである場合）: 実写が主役の動画。同時に複数の作業を走らせない

## 手順

1. 依頼書を 1 カット 1 行の編集計画に直す。番号は依頼書のカット番号をそのまま使う。フックの 3 案は `variant` で分け、
   「フック 1 案 + 本編 + CTA」を 1 本として案の数だけ書き出す。依頼書に無い判断は `note` に理由を書く

   ```yaml
   cut: "1.A"
   phase: フック
   variant: A
   duration_sec: 1.5
   video: {file: materials/footage/salon_front.mov, source_in_sec: 16.0}
   voiceover: {text: "昼休みにカット、間に合うの？"}
   texts:
     - {content: "昼休み", style: keyword_large}             # 大きなキーワード
     - {content: "にカット、間に合う？", style: sub_line}    # 説明の行
   se: ["ハサミのシャキッ"]
   note: 使う区間が依頼書に無いため、手元が映る 16 秒以降を選んだ
   ```
2. 総尺を検算する。上限は依頼書の合計に 1 割を足した長さ。超えたら、まず音声の前後と句の間の無音を詰める。
   それでも超えるなら、自分で決めずに人に判断を返す（文を削るか・話す速さを上げるか・上限を緩めるか）
3. タイムラインを組み、依頼書に書かれていない細部は下の既定値で決める
4. 書き出し設定（尺・解像度・フレームレート・コーデック）を ffprobe で読み取り、依頼書と 1 つずつ照らす
5. 1 秒 1 コマの一覧画像を開き、テロップの誤字（依頼書と 1 文字ずつ照らす）・切れ・はみ出し・書体の太さ・
   意図しない黒い画面・カットの順番と尺を確かめる。通ったら人に確認を依頼する。直しは該当するカットだけを直して書き出し直す

```bash
# 発話の区間をおおまかに見つける（-30dB 以下が 0.3 秒以上続いた箇所を無音として書き出す）
ffmpeg -i vo.m4a -af silencedetect=noise=-30dB:d=0.3 -f null - 2> silence.log
# 尺・解像度・フレームレート・コーデックを確かめる
ffprobe -v error -select_streams v:0 \
  -show_entries stream=width,height,r_frame_rate,codec_name -show_entries format=duration \
  -of default=noprint_wrappers=1 out.mp4
# コンタクトシート（1 秒 1 コマを 6×5 枚に並べて 1 枚の画像にする）
ffmpeg -i out.mp4 -vf "fps=1,scale=320:-1,tile=6x5" -frames:v 1 sheet.png
# 意図しない黒い画面が挟まっていないか（0.1 秒以上の黒を書き出す）
ffmpeg -i out.mp4 -vf "blackdetect=d=0.1:pix_th=0.10" -an -f null - 2> black.log
# 字幕を焼き込む（映像だけ作り直し、音声はそのまま通す）
ffmpeg -i in.mp4 -vf "subtitles=sub.srt" -c:a copy out.mp4
```

## 既定値（依頼書に指定が無いとき）

- テロップは 2 段階（数字・価格・商品名などの大きな言葉と、説明の行）にし、大きさに 2〜3 倍の差をつける。1 行は 16 文字以内、最大 2 行
- 文字の色は白に濃い色の縁取り。明るい背景の上に白い文字を直接置かない
- 文字は媒体の安全な範囲の内側に置く（Meta はリール広告で画面の上 14%・下 35%・左右 6% を避けるよう勧めている。執筆時点。公式で確認）
- ナレーションのあるカットには、テロップの欄が空でも要点を文字で出す
- カットのつなぎは基本カット切り。冒頭 3 秒は 2 カット以上。フックの文字は即時に出し、ほかは 0.2〜0.3 秒で出す
- ロゴは文字で代用せず、素材のロゴ画像を使う。素材の現場の音は、指定が無ければ使わない
- ffmpeg だけで組むとき: 静止画にゆっくりした拡大・移動を付けてカットごとの短い動画にしてからつなぐ。
  テロップは字幕ファイルで焼き込むか、文字入りの画像（image-video-gen の `render_html.py`）を重ねる

## 守ること

- 構成・文言・数値を変えない。価格や割引率は依頼書のテロップの文言をそのまま使う
- 環境に無い書体名を指定しない（エラーを出さず別の書体で書き出される）。最初の書き出しで太さを目で確かめる
- 動かないツールの名前で「作りました」と書かない。実在の店舗・人に見える映像を生成で補わない
- 検品を通らないものは成果物にしない。投稿と入稿はしない

## 出力の型

MP4（フックの案ごと）/ 編集計画（依頼書に無い判断と理由を含む）/ 検品の結果（確かめられなかった項目は「未確認」）

```markdown
| 項目 | 依頼書 | 実際 | 判定 |
|---|---|---|---|
| 解像度・フレームレート・尺・コーデック | | | |
| テロップの誤字・切れ | なし | | |
| 黒い画面の混入 | なし | | |
| 安全な範囲 | 内側 | | |
```

## フォールバック先

- 選んだツールがその環境で動かない: video-production の作り方の選択に戻り、動くツールで組む。使ったツールを正直に書く
- ffmpeg / ffprobe が無い: 書き出しの設定は編集ツールの表示から読み取り、「プログラムでの検品は未実施」と書く
- どのツールも動かない: 編集計画まで作って納品し、何があれば動画まで進むかを書く
