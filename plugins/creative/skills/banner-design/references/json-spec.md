# JSON の設計書

構成が決まったら、画像生成 AI への指示を文章ではなく JSON の設計書として書き、その JSON をそのままプロンプトとして渡す。
HTML で組むときも、同じ JSON を設計書として使う（zone の位置と比率を CSS に写す）。

## 書き方のルール

- 文言はすべて `text` / `content` の欄に、確定した文字列で書く。「〜のようなコピー」と書かない
- 位置は「幅◯%・高さ◯%・どこ」で書く。1 要素 = 1 項目にする
- 色は色名か色コード（「青系」ではなく「青(#1E7FBF)から緑(#2BA084)へのグラデーション」）
- 文字の大きさは 3 段階まで（特大・大・中）。強調は `decoration` の欄に書く
- 写真に無いもの（料理・人物）を写真の指示に書き足さない
- `constraints` の 3 行は毎回そのまま入れる（外すと、指定していない文言が混ざる）
- サイズごとに JSON を分ける

## テンプレート（キャッチコピー型）

架空のブランドの例。文言・色・ロゴを確定した情報に差し替える。構造（zone の分け方）は変えない。

```json
{
  "task": "運用型ディスプレイ広告の静止画バナー（宿泊・キャッチコピー型）",
  "quality_bar": "実際に配信されているプロ制作のバナー。素人感・AIっぽさゼロ",
  "canvas": {"ratio": "1:1", "style": "明るい自然光の写真の上に、コピーの色パネルを重ねる"},
  "layout": [
    {"zone": "左パネル（幅55%・高さ75%・上下中央・左端から余白5%）", "element": "コピーパネル",
     "background": "藍(#1F3A5F)から深緑(#2E6B5A)への斜めグラデーション",
     "text": [
       {"content": "平日なら、", "font": "太いゴシック体", "color": "白", "size": "特大"},
       {"content": "露天を二人だけで", "font": "太いゴシック体", "color": "白", "size": "特大"},
       {"content": "平日休みのあなたへ", "font": "太いゴシック体", "color": "白", "size": "大"}
     ]},
    {"zone": "右側（背面全体）", "element": "写真",
     "content": "朝もやの山あいと紅葉の木立、建物と人物なし、明るい自然光、ストックフォト品質"},
    {"zone": "最下部の白帯（高さ12%）", "element": "フッター",
     "left": {"logo": "<ロゴの説明>", "text": "<屋号>"},
     "right": {"element": "CTAボタン", "shape": "角丸長方形", "background": "オレンジ(#F5A623)",
               "text": "空室を見る ＞", "color": "白"}}
  ],
  "constraints": [
    "テキストは上記で指定した文言のみ。一字一句正確に。誤字・創作テキスト禁止",
    "すべての文字が判読可能",
    "ウォーターマーク・余計な装飾なし"
  ]
}
```

## ほかの型で変えるところ

- 利用シーン型: 写真の zone を背面全体に置き、「一番うれしい 1 シーン」を `content` に具体的に書く。下部の色帯に価格や強み・ロゴ・CTA をまとめる
- 比較型: 写真は使わず、左右分割を 1 つの zone で書く（左 = 従来の方法 / 右 = 新しい方法 / 中央 = 不等号）。
  constraints に「グラフに目盛りや数値ラベルは入れない」を足す（書かないと架空の数値が描き込まれる）
- テキスト型: 赤・白・黒のチラシ風。表組みは `{"label": "料金", "value": "◯◯円〜"}` の行の配列で渡す。
  constraints に「文字はすべて水平に組む」を足す
- クチコミ型: 声は実在の利用者のものだけ。顔を含む生成画像を「お客様の声」に使わない。実在の写真を使うなら HTML で組む

## HTML で組むときの基準

- 2 倍の解像度で画像化する。元の解像度より大きく引き伸ばした写真を背景にしない
- フォントを指定する（その環境に入っている日本語フォントの名前だけを使う）。行間 1.2〜1.4、余白は 8 の倍数

## よく出る崩れと対処

| 症状 | 対処 |
|---|---|
| 位置・比率が無視される | 文章で書いている。`zone` に「幅◯%・高さ◯%・位置」で書き直す |
| 指定していない文言が増える | constraints の「指定した文言のみ」が抜けている |
| 文字が斜めに散る | 「文字はすべて水平に組む」を constraints に足す |
| 作り直しても誤字が残る | 背景だけを生成し、文字は HTML で重ねる |
