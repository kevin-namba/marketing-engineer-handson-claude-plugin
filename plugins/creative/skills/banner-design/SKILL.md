# 静止画バナーの設計

## 最初に確定すること

- 入力: 確定したコピーの文言（ad-copy で決めたもの。ここで言い換えない）、オファー、使える素材（写真・ロゴ・色）、媒体と配信面とサイズ
- コピーが未確定なら、先に ad-copy で確定させる
- 実在の写真があるかが与件に書かれていなければ、画像化の前に 1 回だけ確認する。設計（手順 1〜3）はその間に書き切る
- 入稿・配信はしない。人の確認に渡すところで止める

## 手順

1. 要素を洗い出す（訴求・オファー・証拠・行動のうながし・ロゴ）。優先順位と「なぜ入れるのか」を 1 行ずつ書き、説明できない要素は外す
2. 構成の型から 1 つ選び、理由を 1 行で書く: キャッチコピー型・利用シーン型・比較型・テキスト型・クチコミ型など
   （一覧は `references/layout-types.md`）
3. 設計仕様を JSON で書く（`references/json-spec.md` の共通形と型ごとの書き方に従う）。
   位置・比率・文字の大きさを散文で済ませず、文言は確定した文字列で書く。サイズごとに JSON を分け、画像と同じ場所に保存する
4. 画像にする経路を、下の「経路の選び方」で 1 つ選ぶ。選んだ理由を成果物と一緒に残す。
   実行（API の呼び出し、HTML の画像化、履歴の保存）は image-video-gen の手順とスクリプトを使う
5. 初回は 5 本（本数は仮説の数）。派生は 1 回に 1 か所だけ変え、元の案（`variant_of`）と変えた箇所（`changed`）を記録する。
   ファイル名は `{訴求軸}_{コピー型}_{構成型}_{媒体}_{サイズ}_{版}`（例: `yoyaku3d_after_catch_meta_1080x1080_v02.png`）
6. 画像を開いて全文字を JSON の文言と読み合わせる。誤字が 1 文字でもあれば配信に使わない。
   誤字は修正の指示を重ねず、JSON を確かめて作り直す。最後に、1 秒で内容が読み取れるかをスマホの実寸で確かめる

## 経路の選び方（上から順に当てはめ、最初に当たったもので決める）

1. 主役が実在の写真（客室・料理・スタッフ）→ HTML で帯と文字を重ねる。写真は生成モデルに渡さない
2. 同じデザインで中身だけを差し替えて量産する（口コミの文面・価格・サイズ展開・1 か所だけ変えた派生）→ HTML
3. 生成の API キーがある → 写真風・キービジュアル・背景が主役なら写真に強いモデル、文字入りの図解が主役なら文字に強いモデルで生成
4. API キーが 1 つも無い → HTML で組む。JSON を書いた時点で止めない

## 守ること

- 「文字が崩れないから」で HTML を選ばない。文字の崩れは検品で見つけて作り直す。作り直しても直らないときだけ、背景を生成し、文字を HTML で重ねる
- 文字は 2 階層（大きな見出しと説明の行）にし、大きさに 2〜3 倍の差をつける
- 計測する数字はクリック率が先。見た目の好みで勝ち負けを決めない
- 実在の店舗・スタッフ・料理・客室を生成画像で代用しない。渡された写真に写っていないものを描き足さない。
  与件や LP に無い数字・実績をバナーに載せない
- 画像を作る経路は image-video-gen の 1 つだけ（どのモデルに何を投げたかの履歴が画像の隣に自動で残る）。
  生成画像を使ったら、成果物の説明に「生成画像である」と書く

## 出力の型

構成案（要素の表・選んだ型と理由）→ 設計仕様の JSON（サイズごと）→ 選んだ経路と理由 → 画像（隣に履歴のサイドカー）→ 検品表

```markdown
| ファイル | 作り方 | 書いていない文字 | 誤字 | 要素の抜け | はみ出し・折り返し | 写真の引き伸ばし | 実寸での読みやすさ | 1 秒テスト | 判定 |
|---|---|---|---|---|---|---|---|---|---|
```

生成 AI で作った行は「書いていない文字・誤字・要素の抜け」を、HTML で組んだ行は「はみ出し・折り返し・引き伸ばし・読みやすさ」を埋める。
見ていない欄は「未確認」と書く。

## フォールバック先

- 生成の API キーが 1 つも無い: HTML で組んで画像にする
- ヘッドレスブラウザも使えない: HTML ファイルと JSON の設計書を納品し、「画像化は未実施。ブラウザで HTML を開いて指定サイズで保存すれば画像になる」と書く
- 実在の写真が要るのに素材が無い: 生成で代用しない。写真を使わない型（テキスト型・比較型の図解）に変えるか、必要な写真を一覧にして返す
