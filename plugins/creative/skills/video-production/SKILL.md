# 動画を作る

この Skill は作り方を選んで、台本（reel-script）・編集依頼書（storyboard）・編集（video-assemble）の各 Skill に渡す役割だけを持つ。

## 前提（編集に使うツール。環境に入っているものだけを使う）

| ツール | 得意 | 実行環境 |
|---|---|---|
| ffmpeg | 尺取り、字幕の焼き込み、静止画に動きを付けてつなぐ、書き出し後の検品 | クラウド・ローカルの両方 |
| HTML → MP4 のレンダラー（HyperFrames など） | テキストとグラフィックが主役の動画。文言・数値・言語の差し替えで派生を量産 | クラウド・ローカルの両方 |
| ローカルの GUI 編集アプリ（Palmier Pro） | 実写素材が主役の動画。店舗・人物・体験をそのまま見せる | ローカルの Mac のみ |

各ツールの使い方は公式の手順に従う（HyperFrames: https://github.com/heygen-com/hyperframes 、Palmier Pro: https://www.palmier.io/ 。執筆時点）。

## 手順

1. 実行環境を確かめる。Palmier Pro は Mac でしか動かない。クラウドでは候補から外す。ローカルの Mac でも、起動していて
   MCP でつないである場合だけ候補にする。HyperFrames と ffmpeg が入っているかも確かめる（`ffmpeg -version` など）
2. 手持ちの素材を確かめる（実写動画が主役 / 画像はあるが動画は無い / 何も無い）。聞く前に、渡されたファイルと与件を見る。
   与件に書かれていなければ、生成を始める前に 1 回だけ確認する。企画と構成は先に書き切る
3. 作り方を選ぶ（上から順に当てはめ、最初に当たったもので決める）
   - 実写動画が主役で Palmier Pro を使える: storyboard で編集依頼書を作り、人の確認を経て、video-assemble が Palmier Pro で組む
   - 実写動画が主役だが Palmier Pro を使えず、実写が欠かせない: 編集依頼書まで作って納品する。組み立てには Mac が要ると書く
   - 画像はあるが動画は無い: 画像を流し込み、足りないカットだけ生成で補って HyperFrames で編集する
   - 何も無い: 静止画を生成して構図を決め（image-video-gen）、合意を取ってから、動きが訴求のカットだけ動画にして HyperFrames で編集する
4. 選んだら各 Skill に渡す: 台本が無ければ reel-script → storyboard（編集依頼書。人が確認する）→
   足りないカットは image-video-gen → video-assemble（確認の済んだ依頼書・選んだツール・素材）
5. 書き出した動画からフレームを抽出し、テロップの誤字・切れ・尺を確かめる（方法は video-assemble）。通らないものは成果物にしない
6. MP4 の隣に、選んだ作り方の根拠を `route.md` として残す

選ぶときの注意:

- 縦横の比率は判断の材料にならない（HyperFrames でもたて長を作れる）。実写の素材が 2〜3 カットしか無いとき、
  後で文言・数値・言語・尺を差し替える予定があるときは HyperFrames
- 2 つを組み合わせるときは、どちらが主でどちらが補助かを必ず書く
- 数値・料金・CTA のカットは文字と図で作る。生成 AI の動画にするのは、湯気・手元・歩く様子のように写真では伝わらない動きだけ

## 守ること

- 「作れません」で終わらせない。生成の API キーが無くても、画像と HyperFrames（または ffmpeg）のモーションで動画にする。
  動画を頼まれて「代わりに静止画バナーを作ります」を既定にしない
- 実在の店舗・スタッフ・料理を、生成した映像で代わりにしない。実在の写真が少ないときは、実在の写真＋文字と図の動きで作る
- 使っていないツールで作ったと書かない。フォールバックしたときは、何をどの理由で変えたか、何があれば上がるかを成果物に書く
- 薄い素材で指定の尺を埋めるためにカットを水増ししない。動画に載せる数値・実績・価格は、与件か実データにあるものだけ
- 投稿と入稿はしない。人の確認に渡すところで止める

## 出力の型

MP4 / 選んだ作り方と根拠（`route.md`）/ 検品の結果 / 動画まで進めなかったときは設計書（台本・編集依頼書）と、何があれば進めるか。
生成した画像・動画を使ったら「生成したものである」と書く。

```markdown
# 作り方の記録
- 環境: クラウド（Palmier Pro 不可）｜ローカルの Mac（Palmier Pro 可）
- 採用: [作り方] → [ツール]
- 根拠: [どの素材があり、なぜその作り方にしたか]
- 主と補助: [併用したときだけ]
- 素材: [渡された素材] ／ [生成したカットと、使ったモデル]
- 仮に置いた与件: [尺・媒体など、指定が無く仮に決めたもの]
- フォールバックしたこと: [何を・なぜ・何があれば上がるか]
```

## フォールバック先

- HyperFrames が入っていない: ffmpeg で静止画に動きとテロップを付けてつなぐ（video-assemble）。
  文字の多い情報カードは HTML を画像にしてから（image-video-gen の `render_html.py`）動画に入れる
- ffmpeg も無い: 台本・編集依頼書・カットごとの最初のコマの画像まで作って納品し、何を入れれば動画まで進むかを書く
- 画像生成・動画生成の API キーが無い: HTML で組んだ画像と渡された画像だけで構成し、動画化を飛ばして静止画＋動きで作る
- 素材の有無が分からず、確認の答えも得られない: 素材に頼らない構成（文字と図）で作り、素材があれば差し替えられる箇所を書く
