# 分析に使う言葉

静止画や時刻の表を見ながら言葉にするときは、次の言葉に揃える。揃えておくと、複数の動画を比べられる。

## カメラワーク（動きの種類）

固定 / パン / ティルト / ズームイン / ズームアウト / トラッキング / 手持ち

- 動きの方向と速さも分かる範囲で添える（「ゆっくりズームイン」「速いパン（右 → 左）」）
- 1 つのカットに複数の動きがあるときは、主なものを書き、補足に残す

## カメラアングル

正面 / 俯瞰 / あおり / 寄り / 引き / 横 / 斜め / 背面

- 「寄り／引き」は距離、「正面／横／斜め／背面」は向き、「俯瞰／あおり」は高さ。組み合わせてよい（「斜め・寄り」）

## 画面のレイアウトと文字の位置

- レイアウト: 中央配置 / 三分割 / 左右分割
- 文字の位置: 上部 / 中央 / 下部 / 左右寄せ / なし
- たて型の動画では、画面の上下に操作ボタンやアカウント名が重なる。文字が中央に寄っているかも見る

## 全体の型の名前

動画全体を一言で表す。reel-script の本編の型（PREP・新 PASONA など）に当てはまるなら、その名前も書く。例:

- フック → 問題提起 → 解決 → CTA
- 否定のフック → 共感 → 実演 → CTA
- 結果を先に出す → 根拠 → CTA

## 各列の書き方

- 区間の名前: フック / 導入 / 展開 / 山場 / CTA など。フックはおおむね 0〜3 秒
- 技法: 具体的な手法（疑問形のテロップ、短いカットの連続、BGM の切り替え）
- 動作: 映像を作る人が読んで再現できる書き方（「カメラが右へ動く」「演者が商品を持ち上げる」）
- 映像の描写: そのまま撮影と編集に使える細かさ（「明るい」ではなく「白い背景に自然光、やや逆光」）
- 音: BGM の雰囲気と効果音まで。確かめられなければ「未取得」
- 色・効果（補助）: 暖色 / 寒色 / 周辺を暗くする / ぼかし / 切り替えの種類。全体のトーンを決める材料にする
