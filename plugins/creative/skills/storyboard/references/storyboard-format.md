# 編集依頼書の様式と storyboard.json の形

編集者がこの 1 枚だけを見て、追加の質問なしに編集を始められることが完成の条件。
編集依頼書に書くのは、仕上がりの方針と参考にする広告・申し送り・素材の置き場所・カット表の 4 つ。

## 方針・申し送り・素材

- 方針（`policy`）: 3〜5 行。編集ソフトの操作ではなく、仕上がりの方向を書く
- 参考にする広告（`references`）: URL か保存場所と、何を参考にするか。出典と取得日を付ける。無ければ「参考実例なし」
- 申し送り（`handoff`）: 「項目／ルール／具体例」。1 行に 1 つのルール。具体例には実際のカット番号と文言を書く。
  項目はテロップ（フォント・配色・位置）、効果音（擬音で）、BGM（切り替えるカットの番号と終わりのフェードアウトの秒数）、
  カットのつなぎ、個別の演出、書き出し（たて型なら 9:16・1080×1920・MP4・H.264 など。媒体の公式の仕様で確認）
- 文字は媒体が推奨する安全な範囲の内側に置く（Meta はリール広告で画面の上 14%・下 35%・左右 6% を避けるよう勧めている。執筆時点）
- 素材の置き場所（`assets`）: 与件で渡された実際の場所だけを書く。未定なら「未定」

## カット表の列

| 列（キー） | 書き方 |
|---|---|
| カット（`cut`） | 番号。フックは案ごとに `1.A` `1.B` `1.C`。本編は `2, 3, 4…` |
| 区分（`phase`） | `フック-A` `フック-B` `フック-C` `本編` `CTA` |
| 尺（`sec`） | 数値。平均 2〜3 秒、最長 5 秒。超えるときは備考に理由 |
| 映像（`visual`） | カメラの位置・被写体・動きまで（「商品を見せる」だけは不可） |
| テロップ（`telop`） | 文言＋かっこ書きで装飾（太字・白・中央 など） |
| セリフ／ナレーション（`narration`） | 話し言葉。無音のカットは「（無音）」 |
| 文字数（`chars`） | ナレーションの文字数（句読点を除く） |
| 音（`sound`） | 効果音は擬音で。BGM の切り替えもここに |
| 演出意図（`intent`） | 1 行。このカットが無いと何が伝わらなくなるか |
| 編集指示（`edit_note`） | 秒数・間隔・倍率で書く（「0.3 秒でズームイン」） |
| 素材（`asset`） | 使う素材の場所と使う区間（「16 秒以降」） |
| 撮影が必要（`needs_shoot`） | 素材の一覧に無いカットは `true` にし、`asset` は空にする |
| 備考（`remarks`） | 例外の理由、事実の確認待ちなど |

## 構成と検算

- フック（0〜3 秒）: 3 案（A/B/C）。型の違う 3 つを選ぶ。各案の 1 カット目には必ずテロップを出す
- 本編と CTA は 3 案で共通。本編は選んだ型（PREP・新 PASONA など）の順。CTA は 1 つだけ
- 実際に書き出す 1 本 = フック 1 案 + 本編 + CTA。この長さが指定の尺（`meta.duration_sec`）に収まること
- ナレーション: 文字数 ≦ 尺 × 5 ／ テロップ: 文字数 ≦ 尺 × 4。超えたカットは文言を削って合わせる（尺を延ばさない）

## storyboard.json の形

キー名は英語、値は日本語。複数行は `\n` で書く。合計の行は書かない（スクリプトが計算する）。

```json
{
  "meta": {
    "title": "駅前美容室_リール_編集依頼書",
    "product": "駅前の美容室",
    "offer": "初回のカット＋カラーが 30% オフ（平日 11〜16 時の来店のみ）",
    "appeal": "職場から歩いて行けて、平日の昼なら待たずに入れる",
    "duration_sec": 15,
    "media": "Instagram リール 9:16",
    "export": "9:16 / 1080×1920 / MP4 / H.264"
  },
  "policy": ["店内の実写をそのまま見せる。作り込まない"],
  "references": [{"url": "https://…", "note": "速さの参考（取得 2026-10-04）"}],
  "handoff": [
    {"item": "テロップ・配色", "rule": "白文字に濃い色の縁取り", "example": "カット 1.A「昼休みにカット？」"}
  ],
  "assets": [
    {"no": 1, "type": "動画", "name": "店の入口", "cuts": "1.A", "location": "shared/footage/salon_front.mov"}
  ],
  "cuts": [
    {
      "cut": "1.A", "phase": "フック-A", "sec": 3,
      "visual": "店の入口を正面・引きで。ドアが開いて店内が見える",
      "telop": "昼休みにカット？（太字・白・中央）",
      "narration": "昼休みにカット、間に合うの？", "chars": 13,
      "sound": "ドアベル「カラン」",
      "intent": "何の動画かを 1 秒で伝える",
      "edit_note": "0.3 秒でズームイン",
      "asset": "shared/footage/salon_front.mov の 16 秒以降",
      "needs_shoot": false, "remarks": ""
    }
  ]
}
```

与件に無い数値がどうしても要るときは、テロップを `【要確認: ◯◯の実測値】` とし、備考に「事実の確認待ち」と書く。数値を作らない。
