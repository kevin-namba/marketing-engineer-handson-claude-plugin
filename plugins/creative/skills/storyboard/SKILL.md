# 編集依頼書（絵コンテ）

完成の条件は 1 つ、「編集者がこの 1 枚だけを見て、質問せずに作業を始められる」こと。
書くのは、仕上がりの方針と参考にする広告・申し送り・素材の置き場所・カット表。

## 最初に確定すること

- 入力: 商材、オファー（価格・条件の文言）、訴求軸、尺、媒体、素材の一覧（場所・内容・長さ・顔を出してよい人）、
  台本（reel-script の成果物があれば）、参考にする広告の要約（あれば。出典の URL と取得日を付ける）、出力先
- 足りないものは人に聞く（推測で埋めない）。質問は 1 回にまとめる
- カット表の設計はメインのコンテキストで行わず、サブエージェント `storyboard-designer` に任せる

## 手順

1. メイン: 与件と素材の一覧を揃える
2. サブエージェント: `storyboard-designer` を起動して次を渡し、フック 3 案とカット表を JSON で書き出させる

   ```text
   【与件】商材: ___ / オファー: ___ / 訴求軸: ___ / 尺: ___ / 媒体: ___
   【素材の一覧】___（場所・内容・長さ・顔を出してよい人）
   【台本】___（無ければ「なし」）
   【参考広告の要約】___（無ければ「なし」）
   【様式】${CLAUDE_PLUGIN_ROOT}/skills/storyboard/references/storyboard-format.md を読んで従う
   【検算】python3 ${CLAUDE_PLUGIN_ROOT}/skills/storyboard/scripts/check_storyboard.py <出力した JSON>
   【出力先】outputs/edit-briefs/<商材>/storyboard.json
   書き出したら検算を実行し、保存場所と 5 行以内の要約だけを返してください。
   ```
3. サブエージェント: カット表の中身ではなく、保存場所と 5 行以内の要約だけを返す
4. メイン: 検算し、編集依頼書を書き出して検品する（スクリプトは標準ライブラリのみ。`--csv` でカット表を CSV にもできる）

   ```bash
   python3 "${CLAUDE_PLUGIN_ROOT}/skills/storyboard/scripts/check_storyboard.py" \
     outputs/edit-briefs/<商材>/storyboard.json --md outputs/edit-briefs/<商材>/brief.md
   ```

   WARN が 0 件でなければ差し戻す（意図した例外は備考に理由を書かせる）。`brief.md` を下の検品表で確かめ、
   落ちた項目があれば修正の指示と一緒に差し戻す。1〜2 マスの直しはメインが JSON を直してよい（直したら検算をやり直す）
5. すべて通ったら人に確認を依頼する。確認が済んでから編集（video-assemble）に進む

## 検品表

- 映像の欄が、カメラ位置・被写体・動きまで書かれている。撮影済み素材には場所と使う区間がある
- 編集指示が秒数・間隔・倍率で、効果音が擬音で書かれている
- フックが 3 案あり、本編と CTA は 3 案で共通になっている
- 価格・割引率・時間帯が与件の文言と一致している（1 つずつ照らし合わせる）
- 参考にする広告に出典と取得日がある。再生数などの数字を推測で書いていない
- 素材の一覧に無いカットに「撮影が必要」の印があり、生成で補う前提になっていない
- 申し送りの例が、実際のカット番号と文言を指している
- 音を消して文字だけ読んでも筋が通る。書き出し設定が配信先と合っている（9:16・1080×1920 など）

## 守ること

- 価格・割引率・時間帯は与件の文言だけを使う。与件に無い数字は書かない。「必ず」「絶対」など、成果を約束する言い方をしない
- 素材の一覧に無いカットを前提にしない。実在の店や人に見える映像を、生成で補う案を出さない
- ナレーションは 1 秒 5 文字、テロップは 1 秒 4 文字まで。超えたカットは文言を削って合わせる
- 見た目が整っていても、数値と事実の項目は必ず確認する
- 表計算ソフトのファイルを作っていないのに「スプレッドシートを作りました」と書かない

## 出力の型

`storyboard.json` / `brief.md`（方針・申し送り・素材の置き場所・カット表・検算）/ 撮影が必要なカットの一覧 /
検品表の結果（落ちた項目と直した内容）

## フォールバック先

- サブエージェントを使えない: メインが `agents/storyboard-designer.md` の「守ること」に従って直接設計する。カット表はファイルに書き、会話には要約だけを出す
- Python を実行できない: カットごとに 文字数 ÷ 尺 を表にして手で検算し、「スクリプトでの検算は未実施」と書く
- 素材の一覧が無い: 人に 1 回聞く。答えが得られないときは、全カットに「撮影が必要」の印を付けて設計する
- 台本が無い: reel-script のルールでフック 3 案と本編・CTA を起こしてから設計する
