# フック・本編・CTA の型

## フックの型

| 型 | 例 |
|---|---|
| 質問 | 「これ知ってた？」 |
| 否定・禁止 | 「まだ買わないでください」 |
| 数字 | 「3 秒で分かる◯◯」 |
| 朗報 | 「ついに発売」 |
| 警告 | 「そのやり方、逆効果かも」 |
| リアクション | 「え、待って」 |
| 比較・使用前後 | 「使う前 → 使った後」 |
| ストーリー | 「実は 3 か月前まで◯◯でした」 |
| 共感 | 「昼休みに髪を切りたい人へ」 |
| 結果を先に出す | 完成した状態を最初に見せる |
| ギャップ | 見た目と中身の意外な差を見せる |

- 選び方の目安: 顕在層は質問・数字・結果を先に出す／潜在層は否定・共感・警告／若い層の多い媒体はリアクション・ギャップ・比較
- 数字の型は、与件にある実数だけで作る（「90% が知らない」のような根拠の無い数字を作らない）
- 警告・否定の型は不快にもなる。指摘のあとに必ず解決を置く
- 無音で引くフックでも、画面の文字は省かない

## 本編の型

| 型 | 流れ | 向いている用途 |
|---|---|---|
| PREP | 結論 → 理由 → 具体例 → 結論 | 15〜20 秒の短尺。何かを教える内容 |
| 新 PASONA | 問題 → 親近感 → 解決策 → 提案 → 対象の絞り込み → 行動 | 申し込みに直結させたいとき。あおらずに訴求する |
| AIDCA | 注意 → 関心 → 欲求 → 確信 → 行動 | 権威づけの効果が大きい化粧品・健康食品 |
| ストーリー型 | 主人公としての顧客 → 問題 → 案内役としての商品 → 計画 → 行動 → 成功 | ブランドを知ってもらう動画 |

## CTA の型

| 型 | 例 | 使いどころ |
|---|---|---|
| 押す | 「今すぐ予約」 | 関心の高い層 |
| 誘う | 「詳しくはプロフィールへ」 | 検討中の層。抵抗感が小さい |
| 期限 | 「今月末まで」 | 急ぐ理由を足す。事実のときだけ |
| 数量 | 「1 日 3 組まで」 | 事実のときだけ使う |
| 特典 | 「初回 30% オフ」 | 最後のひと押し。条件は offer-design で決めたとおりに |
| 質問を返す | 「行きたい人はコメントで『行く』」 | 反応を集めたいとき |

## 審査で落ちない書き方

- 実績には注意書きを添える（「※個人の感想であり、成果を保証するものではありません」など）
- 成果を約束する言い方を避ける（「必ず痩せます」ではなく「目指せます」）
- 台本と LP の言葉・数字・商品名を完全に一致させる
- 期間とセットの実績（「1 か月で◯kg」など）は落ちやすい。実績あり版と実績なし版の 2 本を用意する
- 落ちたら実績なし版に差し替え、原因を動画 → LP → 広告文の順に探す（差し替えは人が行う。落ちたものを自動で出し直さない）
