# 情報源・確かさ・点数の要因

> `seo-backlinks` の SKILL.md の手順 1・4 から読む。仕様（無料枠・上限）は執筆時点のもの。使う前に各社の公式ドキュメントで確かめる。

## 情報源と確かさの重み

| 情報源 | 確かさの重み | 認証 | 任意のドメインを調べられるか | 取れないもの |
|---|---|---|---|---|
| 実際に開いて確認 | 0.95 | 不要 | 可（既知のリンク元に限る） | 知らないリンク元の発見 |
| 被リンクの API（Moz Links API など） | 0.85 | API キー（無料枠は限定） | 可 | 増減の推移。指標は各社の推定値 |
| Bing Webmaster Tools | 0.70 | API キー | **所有確認が済んだ自社サイトだけ** | Google の数字。Bing のインデックスの外のリンク |
| Common Crawl | 0.50 | 不要 | 可 | **参照ドメインの一覧**・アンカーテキスト・ページ単位のデータ |

- Bing の数字は Google の数字ではない。並べて出す（足さない）
- Bing Webmaster Tools のデータは、本書で紹介した CLI（`bwt`）でも取れる。URL の送信（submit）は外部への反映なので、この Skill からは送信しない
- 無料のデータの偏り: 人気のあるサイトほど多くクロールされ、小さなサイトは少なく見える

## 点数の計算（ここ 1 箇所に固定）

```
点数 = Σ（要因の点数 × 確かさ × 要因の重み） ÷ Σ（確かさ × 要因の重み）
```

| 要因 | 重み | 主な情報源 |
|---|---|---|
| 参照ドメイン数 | 22 | 被リンクの API |
| リンク元の質の分布 | 22 | 被リンクの API |
| アンカーテキストの自然さ | 17 | 被リンクの API / Bing |
| 不自然なリンクの割合 | 22 | 被リンクの API（スパムの指標） |
| follow / nofollow の割合 | 6 | Bing / 実際に開いて確認 |
| リンク元の地域 | 11 | Bing |

- 分母に入れるのは、データのあった要因だけ（取れなかった要因は 0 点にせず計算から外す）
- **データのある要因が 4 つに届かなければ、点数を出さない**（「データ不足（6 要因中 n 要因）」）
- 情報源が Common Crawl だけなら、点数の上限は 70
- 重みは運用上の目安で、Google の評価の配分ではない。変えるときはこの表を直し、変えた日をレポートに書く

要因ごとの点数（0〜100）の付け方の目安。ツールの提供元や運用の経験則にもとづく値で、Google の基準ではない。
小さな店舗のサイトでは、参照ドメインが 20 未満でも、関係のある組織からのリンクが揃っていれば問題にしない。

| 指標 | 良好 | 注意 | 弱い |
|---|---|---|---|
| 参照ドメイン数 | 100 超 | 20〜100 | 20 未満 |
| follow の割合 | 60% 超 | 40〜60% | 40% 未満 |
| ドメインの偏り | 1 つのドメインが 5% を超えない | 1 つのドメインが 10% 超 | 1 つのドメインが 25% 超 |

計算の途中（要因ごとの点数・情報源・確かさ・重み）は表にして残す。取れなかった要因は点数の欄に「未取得」と理由を書く。
