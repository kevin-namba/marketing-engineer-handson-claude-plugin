# サイト全体の SEO 監査

> `seo` の SKILL.md「サイト全体の SEO 監査」の節から読む。読むだけの監査で、サイトの変更・サイトマップの送信はしない。

## 業種の見立て（トップページのシグナル）

| 業種 | シグナル |
|---|---|
| 店舗（ローカル） | 電話番号・住所・営業時間・対応エリア・地図の埋め込み |
| EC | /products・/collections・/cart、「カートに入れる」、商品の構造化データ |
| メディア | /blog・/articles・/topics、記事の構造化データ、著者ページ、公開日 |
| SaaS | 料金ページ、/features・/integrations・/docs、「無料で試す」「登録」 |
| 代理店 | /case-studies・/portfolio、「実績」、クライアントのロゴ |

## クロール

- 上限は最大 500 ページ。指定が無ければ 100 ページ程度から始める。上限に達したら打ち切り、クロールした範囲を書く
- 同時に取るのは 5 本まで、間隔は 1 秒。リダイレクトは 3 回まで。robots.txt で禁止されているパスは取得せず、そのパスを報告する
- ブラウザのツールがあれば、最初の HTML と描画後の HTML を両方取る。無ければ「JavaScript で描画される内容は未確認」と書く
- ページごとに控える: URL / ステータス / title / meta description / canonical / robots の指定 / h1 / 内部リンクの数 / 構造化データの型

## 統合スコアの重み（ここ 1 箇所に固定）

| カテゴリ | 渡す先 | 重み |
|---|---|---|
| テクニカル | 下の点検項目 | 22% |
| コンテンツの質 | `seo-content` の「ページ品質の点検」の節 | 23% |
| ページ内の要素（title・見出し・内部リンク） | `seo-technical` の「ページ診断」の節 | 20% |
| 構造化データ | `seo-technical` の「構造化データ」の節 | 10% |
| 表示速度（実利用者の値） | `seo-measurement` の「表示速度の計測」の節 | 10% |
| AI 検索対応 | `ai-search-optimization` の「AI の回答での可視性」の節 | 10% |
| 画像 | `seo-technical` の「画像の最適化」の節 | 5% |

- サイトマップ・見た目・検索体験・Google の実測・被リンク・シグナルがあるときの担当は、統合スコアに入れず所見として並べる
- 取れなかったカテゴリは 0 点にしない。重みから外して配り直し、「7 カテゴリ中 n カテゴリで算出」と書く
- 算出できたカテゴリが 4 つに届かなければ、統合スコアは出さない。表示速度をラボの点数で代用しない
- 重みは運用上の目安で、Google の評価の配分ではない。実行ごとに変えない

## テクニカルの点検項目

項目ごとに pass / warn / fail を付け、根拠（URL と実測値）と取得経路を添える。

| 項目 | 見ること |
|---|---|
| クロール | robots.txt（存在・CSS / JS / 画像を止めていない）/ XML サイトマップ / noindex が意図したものか / 重要なページがトップから 3 クリック以内 |
| インデックス | canonical（自分自身を指す・noindex と同時に付いていない）/ 重複（パラメータ・www の有無・http と https・末尾のスラッシュ）/ 主要ページの URL 検査 |
| 最初の HTML | title・canonical・robots の指定・構造化データが、最初の HTML と描画後で食い違っていないか（noindex の食い違いは Critical） |
| 安全性 | HTTPS の強制・証明書・http の資源の混在 |
| URL の構造 | 内容が分かる・リダイレクトは連鎖なし・恒久的な移転は 301 |
| モバイル | viewport の meta・横スクロールが出ない・モバイル版に重要な内容がそろっている |
| 表示速度 | 合否は実利用者の値（75 パーセンタイル）。無いページは「未取得（訪問が少ないサイトでは正常）」 |

## 重大度

| 重大度 | 定義 | 期限の目安 |
|---|---|---|
| Critical | インデックスを止めている、または手動による対策につながる | すぐ直す |
| High | 順位や流入に大きく影響する | 1 週間以内 |
| Medium | 改善の余地 | 1 か月以内 |
| Low | あれば望ましい | バックログ |

同じ原因から出ている所見は 1 件にまとめ、影響するページ数を書く。アクションプランは依存の順に並べる:
インデックスを止めている問題 → 重複と正規化 → ページ内の要素 → 中身 → 外側の裏づけ。
