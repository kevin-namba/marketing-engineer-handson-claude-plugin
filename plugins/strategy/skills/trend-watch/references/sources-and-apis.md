# 話題を拾う面と、各媒体の API

手順 1 で拾う面を決めるとき、定期実行にするために API を検討するときに読む。

**すべて執筆時点の情報。** 実装する前に、各社の公式ドキュメントで料金・規約・申請の要否を確かめる。

## 公開の面

| 面 | 取り方 | 拾えるもの |
|---|---|---|
| X の話題 | [Yahoo!リアルタイム検索](https://search.yahoo.co.jp/realtime)（公開・ログイン不要） | いま言及が増えている語・業界の語 |
| 検索の急上昇 | Google トレンド（公開）。急上昇ワードは RSS でも取れる: `https://trends.google.com/trending/rss?geo=JP` | 季節の需要の立ち上がり・急上昇の検索語 |
| 業界ニュース | 期間を 24〜72 時間に絞った Web 検索、業界メディアの RSS | 業界の発表・制度の変更・話題の店 |
| TikTok の流行 | TikTok Creative Center を**人が開いて**記録する（自動では集めない） | 流行の音源・企画の形式 |

## 主な API で取れるものと条件

| 取得元 | 状態 | 取れるもの・条件 |
|---|---|---|
| Google トレンドの公開データ（BigQuery） | 取れる（審査不要） | 国別の上位検索語と急上昇語。任意のキーワードの時系列は取れず、ランキングだけ |
| YouTube Data API の急上昇 | 取れる（API キーが要る） | 地域ごとの人気動画一覧 |
| TikTok のトレンド（Discovery API） | 申請が要る | 業種別の人気ハッシュタグ・商用利用可の楽曲・トレンド検索語 |
| Instagram のハッシュタグ検索・他アカウントの公開指標 | 申請が要る | 投稿側の連携とは別の経路と審査。タグ数に上限 |
| Meta の広告ライブラリ（API） | 日本の商用広告は取れない | EU 以外は社会問題・選挙・政治の広告のみ。人が画面で検索するか商用サービス |
| X のトレンド（API） | 取れるが高い | 従量課金で定期取得すると費用が現実的でない。公開面を人が確認する |
| Pinterest のトレンド API | 取れない | 執筆時点で日本のリージョンが無い |

## 記録の型（人が見た話題を残すとき）

| 見た日時 | 面 | 話題 | URL | 言及の規模（見えた数字。無ければ「未取得」） | 記録した人 |
|---|---|---|---|---|---|

言及の規模は、画面に表示されていた数字だけを書く。推定で埋めない。
