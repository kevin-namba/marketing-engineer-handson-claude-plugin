# ブランドリスニング（口コミ・言及の定点監視）

自社のブランドや店舗について「いま外で何が言われているか」をチャネル横断で集め、前回からの差分と要対応をまとめる。単発でも使えるが、定期実行に載せて差分を追う使い方が中心。

## 前提

- 対象は自社（または支援先）のブランド・店舗。競合の評判は扱わない。
- 集めてよいのは公開されている面と、公式 API、人が画面で見て記録した分だけ。
- 頻度は毎週が基本。キャンペーン中・メディアへの露出の直後・炎上への対応中は毎日。定期実行に載せるときは [references/fixed-point-monitoring.md](references/fixed-point-monitoring.md) を読む。

## 手順

1. **前回の数字を読み込む。** 前回のレポートか記録シートから取る。見つからなければ「今回が初回。前回との差は次回から出せる」と書く。
2. **表記ゆれを並べてから検索する。** ひらがな・カタカナ・英字・略称・旧店名。否定的な言及ほど正式名では書かれないので、正式名だけで検索しない。Web は「[店名] 口コミ」「[店名] ひどい」まで含める。

   | チャネル | 取り方 | 取れないとき |
   |---|---|---|
   | Google マップの口コミ | 自店舗なら Google ビジネス プロフィールの管理画面の口コミ一覧か公式 API。無ければ公開ページを読む（件数を区切り、CAPTCHA が出たら中断する） | 人が管理画面の口コミ一覧の画面写し（直近 30 日分）を渡す |
   | 予約・グルメ・美容・宿泊のサイト | 自動では開かない（食べログ・ホットペッパー・じゃらんは、利用規約が営利目的や承認外の方法での利用を禁じている）。店舗の管理画面の口コミ一覧の書き出し・画面写しを読む | 届かなければ「未取得」 |
   | X | Yahoo!リアルタイム検索（公開・ログイン不要。件数を区切る）。または公式 API | 人が検索画面を見て記録する |
   | Instagram / TikTok | 公式 API か、人が画面で見て記録した表 | 記録が無ければ「未取得」 |
   | Web 記事・ブログ | 期間を指定した Web 検索。Google アラートの RSS | 検索語を言い換えて再検索 |

3. **チャネルごとに件数・評点・新着を数える。** 数えるのはコードで行い、生成 AI には本文の要約とトーンの判定だけを任せる。本文まで読むのは前回以降の新着だけ。
4. **要対応を分ける。**

   | 区分 | 判定 | 次の動き |
   |---|---|---|
   | 要対応 | 事実誤認 / 衛生・安全への言及 / 返金・クレームの明言 / 同じ話題が複数チャネルに出ている | 対応の下書きを作り、レポートの先頭に置く |
   | 経過観察 | 単発の否定的な言及、本文の無い低評価 | 次回の差分で増減を見る |
   | 活用 | 熱量の高い好意的な言及・利用者の投稿 | 転載の許諾を取ったうえで投稿の素材にする提案 |

5. **レポートにまとめる。** 「一言でいうと」から始め、要対応を先頭に置く。チャネル別の数字の表（件数・評点・前回比・取得日）を残し、次回の比較に使う。

## 守ること

- X・Instagram・TikTok の画面を自動で集めない（各社の規約が禁じている）。ログインが要る面は取らない。
- 開けなかったチャネルは「未取得」と書き、0 件と書かない（「言及が無かった」と「見られなかった」は別の事実）。
- チャネルをまたいで件数を合算しない（数えているものが違う）。
- 「急増」は「直近 7 日で 18 件、前週は 3 件」のように期間と実数で書く。
- 返信・投稿はしない。対応の下書きまでを人に渡す。通知先を決めてから定期実行に載せる。

## 出力の型

```markdown
# 評判の定点レポート: [ブランド / 店舗名]（[期間]）

## 一言でいうと
[今回いちばん伝えること 1〜2 文]

## 要対応（あれば先頭）
- [何が・どこで・いつ] — 根拠: [URL]（取得日）
  - 対応の下書き: [本文]（投稿前に店舗が確認する）
  - 店舗への確認事項: [裏の取れていない点]

## チャネル別の数字（次回の比較にも使う）
| チャネル | 件数 | 評点 | 前回比 | 取得日 | 取り方 |
|---|---|---|---|---|---|
（開けなかったチャネルは「未取得」。合計の行は作らない）

## 言及の例
[トーン別に代表例。すべて URL つき]

## 次にやること（3 つまで。担当と期限つき）
```

## フォールバック先

- 開けないチャネルがある: 開けたチャネルと Web 検索で作り、欠けたチャネルを「未取得」と明記する。どのチャネルも開けないときは、店舗に「管理画面の口コミ一覧の画面写し（直近 30 日分）」を頼む。
- Instagram・TikTok の記録が無い: 人が見て記録するための空の表（日付・URL・要旨・トーン）を渡す。
