# 定例レポート

「全体としてうまくいっているのか」に答える定例レポート。**同じ様式・同じ期間で並べ、目標と前回に対する判定を付ける**。全体の調子は合計ではなく、チャネルごとの判定を並べた表で示す。

## 前提

- 読み手は広告に詳しくない人（店舗のオーナー・広報担当・経営者）。本文を書き始める前に [references/plain-report.md](references/plain-report.md) を読む。
- 数字の取り方は、チャネルごとに次の順で決める: 媒体・解析ツールの MCP ツール → 公式 API / 公式 CLI → 管理画面から出した CSV → 利用者が貼った数字。どれで取ったかをレポートに書き、前回と同じ取り方にする。
- 検索順位・アクセス・広告の実績は、公開ページの数字で代替しない。売上・LTV・解約率は、利用者から受け取ったときだけ載せる。

## 手順

1. **つながっているチャネルを確かめる。** 実際に数字が取れたものだけを載せる。取れないチャネルは「未取得」と書き、つなぐ方法を添える。

   | チャネル | 主な取得元 | 出せる数字 |
   |---|---|---|
   | 検索 | Search Console | 表示・クリック・クリックされた割合・掲載順位 |
   | サイト | GA4 | 訪問・申し込み（GA4 側の定義で） |
   | 広告 | 各媒体（Meta / Google / TikTok / LINE ヤフー など） | 広告費・表示・クリック・媒体ごとの CV・1 件あたりの費用 |
   | SNS | 各アカウントのインサイト | フォロワー・投稿ごとの反応（アカウント 1 つずつ） |
   | Google マップ | ビジネス プロフィールのパフォーマンス | 表示・行動（電話・経路・サイト）・口コミの件数と評点 |

2. **目標と前回の数字を集める。** 目標は案件の設定から引く。無ければ前回比だけで組み、冒頭に「目標が未設定」と書く。前回の数字は、前回のレポート末尾の数値表 → 記録シートの順に探し、見つからないときは「今回が基準」と書く。
3. **チャネルごとに同じ期間の数字を並べ、判定する。** ◎（良い）○（想定内）△（注意）✕（悪い）の 4 段階と、理由を 1 行。未取得は「—」で判定しない。合計の行は作らない。前回比・1 件あたりの費用の計算はコードで行う。
4. **気になることを先頭に書く。** 「期間 + 実際の数字 + 変化量」で名指しする（例: 「10/1〜10/31 の自然検索のクリックは 820 回。前月 1,240 回から 34% 減った」）。
5. **次にやることを 3 つまで書く。** 判定が △ か ✕ のチャネルだけを、それぞれの分析の手順へ回す。担当と期限を付ける。
6. **末尾に次回のための数値表を残す。** チャネル・指標・値・期間の表。次回はこの表を前回の数字として読む。

## 守ること

- **チャネルの数字を合計しない。** 2 つ以上の広告媒体の CV、TikTok の再生数と Instagram の表示回数、見た人の人数（重複を除いた数）、複数アカウントのフォロワー数は足さない。広告費だけは合計してよいが、合計から 1 件あたりの費用は出さない。
- 予約が 0 件のときは、1 件あたりの費用を「—」と書く（0 円と書くと、安く獲れているように見える）。
- テストの勝ち負けは、growth-experiment の結果をそのまま引用し、判定し直さない。
- 取れなかったチャネルの行を消さない。目標が無いときに、目標を勝手に作らない。
- 単位は取り方ごとに確かめる（例: Search Console API の `ctr` は 0〜1 の比率）。% に直すのは 1 回だけ。

## 出力の型

```markdown
# 定例レポート: [案件名]（[期間]）

## 一言でいうと
[全体の調子と、今月いちばん大事なこと。3 行以内。略語なし]

## 気になること（あれば先頭）
- [チャネル] [期間 + 実際の数字 + 変化量] → [次の一手]

## チャネル別の成績表
| チャネル | 主な数字（意味の文つき） | 目標比 | 前回比 | 判定 | 理由 |
|---|---|---|---|---|---|
| Meta 広告 | 予約 21 件（Meta の数え方）、1 件あたり 7,100 円 | 目標の 8,000 円より安い | −6% | ○ | 素材の入れ替えで費用が少し下がった |
| Instagram | 未取得 | — | — | — | 連携が切れている。連携し直せば次回から載る |
（例の数字は架空。合計の行は作らない）

## テストの結果（あれば）

## 次にやること（3 つ以内。担当と期限つき）

## 詳しく見たい人へ
[指標の明細・取り方・データの限界]

## 次回のための数値表
| チャネル | 指標 | 値 | 期間 | 取り方 |
|---|---|---|---|---|
```

## フォールバック先

- チャネルがつながっていない: 管理画面から出した CSV か、利用者が貼った数字で作る。どちらも無ければ「未取得」の行にして、つなぐ方法（どこで連携するか、どの CSV を出すか）を書く。
- 前回と取り方が違う: その行の前回比は出さず、「取り方が変わったため比べられない」と書く。
- 売上の数字が無い: 広告費 1 円あたりの売上などは出さない。「未取得」と書く。
