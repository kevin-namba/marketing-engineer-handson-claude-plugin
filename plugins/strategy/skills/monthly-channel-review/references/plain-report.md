# 分析レポートの書き方（読み手は広告に詳しくない人）

読むのは広告代理店の運用者ではなく、**店舗のオーナー・広報担当・経営者**。CPA も CVR も ROAS も知らない。**説明が要る数字は、説明ごと書く。** レポートを開いた人が、最初の 1 画面だけで「良かったのか悪かったのか」「その理由」「次に何をするのか」に答えられることが合格条件。

## 構成（この順を崩さない）

1. 一言でいうと … 3 行以内。専門用語ゼロ。数字は多くて 2 つ
2. いま何が起きているか … 事実 ＋ 良し悪しの判定（◎ ○ △ ✕）
3. なぜそうなったか … 仮説であることを明示（「〜と考えられる」）
4. 次にやること … 3 つまで。行の先頭に動詞。担当と期限つき
5. 詳しく見たい人へ … 指標の明細・全件の表・取得方法・データの限界

専門用語・細かい指標表・計算式は 5 に集める。見出しで結論を言う（「クリックは増えたが、予約は減った」のように書く）。

## 数字の書き方

- **数字は必ず「意味の文」とセットにする。**
  - ✕ `CPA: ¥3,200（前月比 +18%）`
  - ◯ 予約 1 件を取るのにかかった広告費は **3,200 円**。先月は 2,700 円だったので 500 円ぶん悪化した。
- **比べる相手を必ず置く**（前月 / 目標）。無いときは「比べる相手が無いので、今回を基準にする」と書く。
- **良し悪しはこちらが言い切る。** 表には判定の列を必ず置く。
- **期間と単位を毎回書く**（「11/1〜11/30 の合計」「1 件 = 予約完了」）。
- **率は人数に言い換える。** 「CVR 2.1%」→「ページを見た 100 人のうち 2 人が申し込んだ」。
- **0 件のときに割り算の結果を書かない**（CV が 0 の CPA は「—」）。
- **取れなかったデータは「未取得」と書き、どうすれば取れるかを添える。** 推測で埋めない。0 と書かない。

## 言葉の言い換え

見出し・「一言でいうと」・「次にやること」には略語を出さない。サービス名・画面名（Meta 広告 / Search Console / Instagram のインサイト）はそのままでよい。スクリプト名・API 名・ファイルパスはレポートに書かない。

| そのまま出さない | 書き方 |
|---|---|
| インプレッション / IMP | 表示回数 |
| リーチ | 見た人数（同じ人は 1 回として数える） |
| CTR | 表示のうちクリックされた割合 |
| CPC | クリック 1 回あたりの広告費 |
| CV / コンバージョン | 申し込み・予約・購入（案件の実際の行動名で書く） |
| CVR | 訪問した人のうち申し込んだ割合 |
| CPA | 申し込み 1 件あたりにかかった広告費 |
| ROAS | 広告費 1 円あたりの売上 |
| クリエイティブ | 広告の画像・動画・文言 |
| LP / ランディングページ | 広告から来た人が最初に見るページ |
| KGI / KPI | 最終目標 / 途中の目標 |
| オーガニック | 広告を使わない自然な流入 |
| セッション / UU | 訪問回数 / 訪問した人数 |
| エンゲージメント | 反応（いいね・保存・コメント・シェア） |

## 出す前の自己チェック

- [ ] 見出しだけ読んで結論が分かるか
- [ ] 「一言でいうと」に略語・カタカナ語が混ざっていないか
- [ ] すべての数字に「比べる相手」と「良し悪しの判定」が付いているか
- [ ] 「次にやること」が 3 つ以内で、担当と期限が書いてあるか
- [ ] 事実と仮説が読み分けられるか
