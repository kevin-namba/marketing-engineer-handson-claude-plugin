# キーワードの実数値

一次情報は Google 広告のキーワードプランナー（同じ数字は Google 広告の API からも取れる）。
この Skill は数字を取って表にするまで。どの語を狙うかの判断は行わない。

## 最初に確定すること

- 地域と言語（既定のまま取らない。日本語 × 日本なら言語 ID `1005`、地域 ID `2392`）
- 対象のキーワードの一覧と、検索パートナーを含めるか（API の既定は含む）

## 取れるもの / 取れないもの

| 項目 | 取れるか | 読み方 |
|---|---|---|
| 月間平均検索ボリューム | 取れる | 直近 12 か月の平均。値が返らないときは「データ無し」で、0 ではない |
| 月別の検索ボリューム | 取れる | 季節性を見る。宿泊や観光は、年平均だけで判断すると繁忙期を見誤る |
| 競合性（LOW / MEDIUM / HIGH）と競合指数（0〜100） | 取れる | 広告枠がどれだけ埋まっているか。SEO の難しさではない |
| ページ上部に表示するための入札単価の下限と上限 | 取れる | 過去の入札額を安い順に並べたときの、下から 20% と 80% にあたる額 |
| 検索順位・検索意図・SEO の難易度 | 取れない | この API には無い。順位と難易度は SEO の Skill で取る |

## 手順

1. 地域と言語を指定する。表には必ず地域と言語を併記する
2. 数字を取る。上から順に試し、取れたら止める
   - 媒体の MCP ツール（キーワードプランナーを呼べるツールをつないである場合。ツールの一覧で確かめる）
   - 公式 API（エンドポイントと返る指標は `references/google-ads-keyword-api.md`。認証情報はツールの側に置く）
   - 管理画面の CSV（「フォールバック先」の文面で 1 回で頼む）
3. ボリューム・単価のレンジ・競合性を 1 行 1 キーワードの表にする。入札単価は 100 万分の 1 の単位（`*Micros`）で返るので、
   1,000,000 で割る。通貨はアカウントの設定通貨で、円換算を推測で書かない
4. 季節変動がある語は、月別の推移（最大の月・最小の月）を一緒に出す
5. 見積もりに使うときは、単価のレンジの**上側**で計算する（想定クリック数 × 上限側の入札単価）

## 守ること

- データ無しを 0 と書かない。値が返らなかったキーワードは「データ無し」として表に残す
- ここの数字を順位の代わりに使わない。競合指数を「SEO 難易度」という列名で出さない
- 平均値を「毎月この件数検索される」と断定しない（幅のある推定値）
- 取れなかったときに数字を作らない。別の推定ツールの値や一般的な目安で埋めない
- 表記ゆれが 1 行にまとめられた語や、範囲で返ったボリューム（概算）は、備考にそう書く

## 出力の型

```markdown
# キーワードの実数値（地域: 日本 / 言語: 日本語 / 取得日: YYYY-MM-DD / 取得経路: …）

| キーワード | 月間平均検索ボリューム | 最大の月 / 最小の月 | 広告の競合性（指数） | 入札単価の下限 | 入札単価の上限 | 備考 |
|---|---|---|---|---|---|---|
| 〇〇 予約 | 12,100 | 7 月 18,100 / 2 月 8,100 | 高（87） | 45 円 | 210 円 | |
| △△ | データ無し | — | 不明 | — | — | 値が返らなかった |

- 見積もり（上限の単価で計算）: …
- 取れなかった項目と取り方: …
```

## フォールバック先

- MCP ツールも公式 API も無い: 管理画面の CSV を 1 回で頼む。「Google 広告の管理画面 → ツール → キーワードプランナー →
  『検索のボリュームと予測のデータを確認する』に次の語を入れ、地域 = 〇〇・言語 = 〇〇・期間 = 直近 12 か月で、
  過去の指標を CSV でダウンロードしてください」。届くまでに、キーワードの設計と定性の優先度を先に作る
- CSV も無い: 実数の列を「未取得」としたキーワード表を返す。推定値を出さない
- 認証エラー: エラーの本文をそのまま伝え、直し方（`references/google-ads-keyword-api.md`）を添える
