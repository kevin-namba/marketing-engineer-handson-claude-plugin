# 媒体で揃っていないもの（1 表）

広告の階層（キャンペーン → 広告セット / 広告グループ → 広告）はどの媒体でも同じだが、金額の単位と、配信の状態を表す語は媒体ごとに違う。
**値の大きさから単位を推測しない。** 毎回この表で確かめる。

この表は執筆時点のもの。使う前に各媒体の公式ドキュメントで確かめる。確かめられなかった項目は「取らない」と決める。

| 項目 | Meta 広告 | Google 広告 | TikTok 広告 | LINEヤフー広告 |
|---|---|---|---|---|
| 金額の単位 | 通貨ごとに決まった数で割る（円は 1、ドルは 100） | 100 万で割る（マイクロ単位。通貨によらない） | そのまま（通貨の小数） | そのまま（円の整数） |
| CTR の単位 | パーセント | 0〜1 の比率 | 単位が明記されていないので、分子分母から出す | 分子分母から出す |
| 配信中の語彙 | `ACTIVE` | `ENABLED` | `ENABLE` | `ACTIVE` |
| 停止の語彙 | `PAUSED` | `PAUSED` | `DISABLE` | `PAUSED` |
| 作成時の既定状態 | 停止を明示する | 停止を明示する | 既定が配信中（必ず停止を指定する） | 停止を明示する |
| 日予算の階層 | キャンペーンか広告セット | キャンペーンのみ | キャンペーンか広告グループ | キャンペーンのみ |
| 何を成果（CV）と数えるか | こちらでアクション種別を選ぶ | 管理画面側の設定に従う | 媒体側の設定に従う | 媒体側の設定に従う |
| 複製 | キャンペーンを停止状態で複製できる | 複製の API が無い | 対象にしない | 複製の API が無い |
| 公式 MCP でできること | 参照と書き込み | 参照のみ | 公開ドキュメントで仕様を確認できなかった | 参照のみ |

## 補足

- **Meta の金額**: 予算は通貨の最小単位で渡す（`6000` = 6,000 円、ドルは `5000` = 50.00 ドル）。
  割る数は公式の表（通貨のオフセット）で決まる。**表に無い通貨では予算の操作を止める**。
- **Google の金額と整数**: 金額は 100 万分の 1 の単位（`*_micros`）で返る。64 ビットの整数は JSON では文字列で返るので、数値に直してから計算する。
- **TikTok**: 何も指定しないと配信中で作られる。作成のツールでは必ず停止（`DISABLE`）を指定する。
  広告グループの日予算は変更が翌日から効く予約になることがあるので、巡回で予算を動かす対象はキャンペーンにする。
- **率（CTR・CVR など）**: どの媒体でも、媒体が返す率をそのまま使わず、クリック数・表示回数・成果の件数から計算し直す。
- **公式 MCP で書き込めない媒体**: 作成や変更まで任せたいときは、媒体の API を呼び出す MCP を自分で用意する。
  公式 MCP のツールも自作のツールも、1 つのパーミッションの設定にまとめて書く。

## 足してよい数字・足してはいけない数字

- **消化額・表示回数・クリック**: 足せる。ただし通貨が違うときは消化額の合計も出さず、理由を書く。
- **成果の件数・CPA**: 足せない。数え方が媒体で違う。
- **投稿の再生数と広告の表示回数**: 別の数字なので足せない。
- **成果 0 件の CPA**: 0 円ではなく「計算できない」（表では「—」）。0 円にすると「CPA が目標より安い = 優良」の条件に当てはまる。
- **取れなかった数字**: 0 で埋めず「未取得」と書き、どうすれば取れるかを添える。
