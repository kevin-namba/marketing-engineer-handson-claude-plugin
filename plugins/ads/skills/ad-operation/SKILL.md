# 広告運用の全工程

新規案件の 1 周目を受け持つ。受け持つのは「どの順番で、どの Skill に、何を渡すか」だけで、判断と実行は各工程の Skill が行う。

## オントロジー（出てくるモノと関係）

- 案件 → 広告アカウント（媒体の ID。一覧から選ぶ）→ キャンペーン → 広告セット / 広告グループ → 広告 → クリエイティブ
- キャンペーンで目的と予算を、広告セット（Meta 以外では広告グループ）で配信先と入札を決め、その下に広告を置く
- 広告は状態を持つ（停止中 / 配信中 / 審査落ち / 判定不能）。状態を取得できないときは判定不能とし、停止中や成果 0 件とみなさない。
  状態を表す語は媒体で違う（`references/platform-differences.md`）
- 計測イベントは広告アカウントが持つ。計測タグとサーバーの両方から来た同じ成果は、イベント ID で 1 件にまとめる
- 広告の数値は、媒体をまたいで足さないままレポートへ渡す
- 任せる操作は、取得・停止状態での作成・素材のアップロード・停止。**配信開始と予算の変更は人が確認する**

## 最初に確定すること（与件把握）

分からない項目は推測で埋めずに、まとめて 1 回で聞く。

- 商材と、成果として数えるもの（予約完了・購入・問い合わせ・友だち追加など）
- 月に使える広告費の上限、期間
- 契約範囲（クリエイティブや遷移先ページの制作を含むか、既存のものを使うか）
- 過去の広告の実績（あれば媒体・期間・CPA）と、既存の広告アカウントの有無

## 工程と渡す先

1. 与件把握（この Skill）→ 与件のまとめを以降のすべての工程に渡す
2. 媒体選定 → `media-selection`。候補を 2〜4 個に絞り、検証の設計と撤退ラインまで決める。
   検索広告の見積もりは `keyword-volume`、目標 CPA と予算は `cpa-budget-plan`
3. クリエイティブ準備 → `ad-copy` / `banner-design` / `reel-script` / `video-production`。
   先に競合の広告を 2 段階で調べる（`references/competitor-ad-survey.md`）
4. 遷移先ページの準備 → `landing-page-builder`。広告の冒頭の言葉と、遷移先の最初の画面の言葉を突き合わせ、
   計測タグの検証結果と成果のイベント名を受け取る
5. 入稿と配信開始 → `meta-ads-playbook`（設計）→ `meta-ads-api`（実行）。**停止状態で**一式作り、
   配信開始は作成の結果を見せてから別に確認を取る
6. 運用チューニング → `meta-ads-playbook` / `weekly-ad-tuning`。基準が決まっている操作は `ad-patrol` に任せる
7. レポート → `ad-weekly-report`。成果の出た型（訴求・構成）は次の企画へ渡す

2 周目以降は、運用ログ（提案 1 件を 1 行で持つ台帳）を作り、定期の見直しを `ad-cycle` へ渡す。
Meta 以外の媒体は、その媒体の公式 MCP か自作の MCP で同じ線引きを守る。書き込みの手段が無い媒体は、
入稿内容の設計書を成果物にし、人が管理画面で入稿する。

## 守ること

- 自分では判断も入稿もしない。各工程の Skill へ渡し、成果物をファイル（`<案件名>-<工程名>.md`）で次の工程へ引き継ぐ
- 媒体を決め打ちしない。媒体選定を飛ばして入稿しない
- 計測タグを検証できていない遷移先には配信しない
- 既存の素材や遷移先ページを使う案件は、その工程を飛ばして入稿へ進んでよい。飛ばした工程は理由と一緒に書く
- 確認画面で断られた操作を別の方法で実行しない

## 出力の型

各工程の終わりに、次を 1 画面で返す。

```markdown
## 工程 N: <工程名>（<渡した Skill>）
- 成果物: <ファイルのパス>
- 要点: （5 行以内）
- 次の工程へ渡すもの: …
- 飛ばした工程と理由: （あれば）
- 人に決めてほしいこと: （媒体の最終決定、予算、配信開始など）
```

## フォールバック先

- 媒体とつながっていない: 工程 1〜4 と、入稿内容の設計書までを仕上げる。入稿は人が管理画面で行い、実績は CSV で受け取る
- 行き先の Skill がこの環境に無い: その工程の成果物の見出しだけ示し、「何があれば進められるか」を書いて次へ進む。黙って飛ばさない
- 計測タグを検証できない: 配信開始へ進まず、検証できない理由と必要な権限を書いて止まる
