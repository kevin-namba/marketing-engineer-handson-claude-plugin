# 一式の入稿（キャンペーン・広告セット・クリエイティブ・広告）

フィールド名は Marketing API の公式の語彙（執筆時点）。使う前に公式リファレンスで確かめる。確かめられない項目は入れない。

呼び出しの前に、素材 → 差出人のページ → 広告の中身（広告文・遷移先 URL・配信地域・予算の置き場所）の順に確定する。
媒体の中での作成の順番は、キャンペーン → 広告セット → 素材のアップロード → クリエイティブ → 広告。前の手順で得た ID を次へ渡す。

## 必須項目（呼ぶ前に数える）

| 部品 | 必須の項目 |
|---|---|
| キャンペーン | `name`、`objective`（例: `OUTCOME_TRAFFIC` / `OUTCOME_LEADS` / `OUTCOME_SALES`）、`status` = `PAUSED` |
| 予算 | `daily_budget` か `lifetime_budget` を、**キャンペーンか広告セットのどちらか一方だけ**に。`lifetime_budget` なら広告セットの `end_time` も |
| 広告セット | `name`、`billing_event`（例: `IMPRESSIONS`）、`optimization_goal`（例: `LANDING_PAGE_VIEWS` / `OFFSITE_CONVERSIONS`）、`targeting.geo_locations`、`status` = `PAUSED` |
| 広告セット（成果に最適化するとき） | `promoted_object`（ピクセルの ID とイベントの種別） |
| 広告セット（広告セット側に予算を置くとき） | `bid_strategy`（上限を付けないなら `LOWEST_COST_WITHOUT_CAP`） |
| クリエイティブ | `name`、`object_story_spec.page_id`（差出人のページ）、`link_data.link`（遷移先 URL）または `video_data` |
| 素材 | 画像なら `image_hash`、動画なら `video_id`。**画像と動画は同時に指定しない** |
| 広告 | `name`、広告セットの ID、クリエイティブの ID、`status` = `PAUSED`。ピクセルで成果を数えるなら `conversion_domain` |

- 画像・動画は先に広告アカウントへアップロードして `image_hash` / `video_id` を得る。
- 素材が実写か生成画像かを確かめる（実在しない料理の写真で、実店舗の広告を出さないため）。
- アップロード直後の動画は媒体側で変換中のことがある。次の手順が失敗したら、作り直さず少し待ってやり直す。

## 予算の置き場所

- キャンペーン側（媒体が広告セットへ自動で配分する）か、広告セット側の一方だけに置く。両方に付けると媒体が弾く。
- キャンペーン側の最低日予算は、広告セット側より高い。少額のテストは広告セット側に置く。
- 最低額は媒体が返すエラーの本文で確かめる。金額を決め打ちで書かない。

## エラーの読み方

Meta の 400 エラーは、原因が本文にしか書かれていない。原因を特定せずに呼び直さない。

| 本文から分かること | すること |
|---|---|
| キャンペーン側の予算が最低額に届かない | 予算を広告セット側へ移す案を見せる |
| 広告セット側の予算が最低額に届かない | 最低額を利用者に見せ、確認が取れたら金額を上げて作り直す。勝手に増額しない |
| 予算が 2 つ指定されている | キャンペーン側か広告セット側の一方だけにする |
| 入札戦略が指定されていない | 広告セットに `bid_strategy` を付ける |
| 連携に使っているアプリが開発モード | 利用者の側では直せない。アプリの設定が要ると伝えて止まる |
| 広告アカウントが、ページに接続された Instagram アカウントを使えない | ビジネス設定で Instagram アカウントを広告アカウントに割り当ててもらうよう伝えて止まる |
| 連携したアカウントが、差出人のページを広告に使えない | ページの「広告」の権限を付けてもらうよう伝えて止まる（権限を付けたあとに連携し直す） |

2 回同じエラーなら、原因は内容ではなく権限や設定にある。「利用者に伝えて止まる」側の扱いに切り替える。

## 途中で落ちたとき・運用中の変更

- 結果に「どこまで作られたか」（作成済みの ID と名前）を載せる。作り直す前に、残ったものを管理画面で削除する
  （消さずに作り直すと、同じキャンペーンが二重に並ぶ）。
- クリエイティブの差し替えは、新しいクリエイティブと新しい広告を停止状態で作り、新しい広告の配信開始で確認を取る。
  既存の広告の中身は書き換えない。古い広告は、許可のあとに停止する。
