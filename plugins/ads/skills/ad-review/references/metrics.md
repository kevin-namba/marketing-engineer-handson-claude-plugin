# 指標の定義と、媒体ごとの単位

## 指標

| 指標 | 計算 | 意味 |
|---|---|---|
| CTR | クリック ÷ 表示回数 | 表示のうちクリックされた割合 |
| CPC | 広告費 ÷ クリック | クリック 1 回あたりの広告費 |
| CPM | 広告費 ÷ 表示回数 × 1,000 | 1,000 回表示するのにかかった広告費 |
| CVR | 成果 ÷ クリック | 訪問した人のうち申し込んだ割合 |
| CPA | 広告費 ÷ 成果 | 申し込み 1 件あたりにかかった広告費（成果 0 件なら「—」） |
| ROAS | 売上 ÷ 広告費 | 広告費 1 円あたりの売上（売上を計測している場合だけ） |

- 率は、媒体が返す値をそのまま使わず、分子と分母から計算し直す。
- どのクリックを分子にしたか（すべてのクリック / リンクのクリック）を明細に書き、期間をまたいで同じものを使う。
- 分母が 0 の率は「—」。0% と書かない。成果 0 件の CPA は「—」。
- 前期間比 = 当期 ÷ 前期 − 1。前期が 0 か未取得なら「—」。目標比 = 実績 ÷ 目標（CPA は低いほど良い。判定の向きを取り違えない）。

## 媒体ごとの単位（執筆時点。公式ドキュメントで確かめる）

| 項目 | Meta 広告 | Google 広告 | TikTok 広告 | LINEヤフー広告 |
|---|---|---|---|---|
| 金額 | 予算は通貨ごとに決まった数で割る（円は 1、ドルは 100）。実績の消化額は通貨の額 | 100 万で割る | そのまま（通貨の小数） | そのまま（円の整数） |
| CTR | パーセント | 0〜1 の比率 | 単位が明記されていないので、分子分母から出す | 分子分母から出す |
| 成果の決まり方 | こちらで行動の種別を選ぶ | 管理画面側の設定に従う | 媒体側の設定に従う | 媒体側の設定に従う |

- **値の大きさから単位を推測しない。** 「1 以下なら比率」と推測すると、Meta の 0.8% を 80% と読む。
- 管理画面の CSV は、API と単位が違うことがある。列の見出しと、1 行を手で検算して確かめる。
- 単位が確かめられない指標は出さない。

## 足してよいもの・いけないもの

| 数字 | 媒体をまたいで足せるか |
|---|---|
| 消化額 | 同じ通貨のときだけ足せる。通貨が違うときは合計を出さず、理由を書く |
| 表示回数・クリック | 足せる |
| 成果の件数 | 足せない（数え方が媒体で違う） |
| CPA・CVR | 足せない・平均しない |
| 投稿の再生数と広告の表示回数 | 別の数字なので足せない |
| リーチ（人数） | 期間や広告セットをまたいで足せない（同じ人を二重に数える） |

## 明細に書く成果の定義

- 何を成果と数えたか（予約完了・購入・リードなど。Meta は選んだ行動の種別の名前）
- 計測の手段（ピクセル・サーバーからの送信）と、成果を数える期間の設定（クリックから 7 日など）
- 期間の途中で定義や計測が変わったときは、その日付。計測していない期間は CPA の計算から外し、そう書く
