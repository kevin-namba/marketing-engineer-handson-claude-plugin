# 実績の取り方（項目・粒度・CSV の頼み方）

フィールド名は各媒体の公式の語彙（執筆時点）。使う前に公式リファレンスで確かめる。

## 粒度

- 階層別（キャンペーン / 広告セット・広告グループ / 広告）× 日次で取り、集計は手元で行う。当期と比較期間の両方を取る。
- 使った経路（MCP ツール / 公式 API / CSV）を明細に書く。経路が変わると単位や集計の期間が変わることがある。

## 取る項目

### Meta 広告

| 区分 | フィールドの例 | 使い道 |
|---|---|---|
| 費用 | `spend` | 消化額 |
| 表示 | `impressions` / `reach` / `frequency` | 表示回数・リーチ・1 人あたりの表示回数 |
| クリック | `clicks` / `inline_link_clicks` | クリック（どちらを分子にするかを固定する） |
| 成果 | `actions`（`action_type` ごと） | **どの `action_type` を成果と数えるかを案件の定義に合わせて選ぶ** |
| 売上（物販） | `action_values` | 売上と ROAS |

- `ctr` / `cpc` / `cpm` も返るが、レポートでは使わず計算し直す。`ctr` はパーセント。
- 現在の日予算と配信の状態は、実績ではなくキャンペーン・広告セットの設定から取る（`daily_budget` / `lifetime_budget` / 状態）。

### Google 広告（公式 MCP の検索のツール）

| 区分 | フィールドの例 | 注意 |
|---|---|---|
| 費用 | `metrics.cost_micros` | 100 万で割る |
| 表示・クリック | `metrics.impressions` / `metrics.clicks` | 文字列で返る。数値に直す |
| 成果 | `metrics.conversions` | 管理画面で「コンバージョン列に含める」とした行動の合計。小数になることがある |
| 日付・階層 | `segments.date` / `campaign.id` / `ad_group.id` | ID で突き合わせる |

- `metrics.ctr` は 0〜1 の比率。レポートでは使わず計算し直す。日予算はキャンペーンの予算のリソースにある。

### TikTok 広告・LINEヤフー広告

- 消化額・表示回数・クリック・成果の件数を、キャンペーン別・日別で取る。率は取らずに、分子と分母から出す。
- LINEヤフーのレポートは、配信の実績が無い行を返さないことがある。行が無いことを「0 件」と読まない。

## CSV を頼む文面（1 回で完結させる）

```
〇〇広告の実績が取得できなかったため、管理画面からの書き出しをお願いします。

- 画面: 広告マネージャ（キャンペーン管理）→ レポート
- 期間: YYYY-MM-DD 〜 YYYY-MM-DD と、比較用に YYYY-MM-DD 〜 YYYY-MM-DD
- 内訳: 日別 × 広告セット（広告グループ）別。できれば広告別も
- 列: キャンペーン ID・名前、広告セット ID・名前、日付、消化額、表示回数、クリック数、成果の件数（何を成果としているかも）
- 形式: CSV
- あわせて: 各キャンペーン・広告セットの現在の日予算と配信の状態（画面のスクリーンショットでも可）

届くまでに、取得できた媒体の分でレポートを先に仕上げます。届いたら同じ形式で追記します。
```

## 取れないときの扱い

- 実際の予約・来店・購入は、クライアントから受け取る。未着なら「未取得」と書き、次回までの依頼に入れる。
- 現在の日予算が取れなければ、予算の再配分は額ではなく向き（増額 / 縮小 / 停止）で書く。
- 途中まで取れたデータは捨てない。取れなかった数字を 0 や平均値、ほかの数字からの推定で埋めない。
