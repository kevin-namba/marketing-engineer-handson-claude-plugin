# Meta（Facebook / Instagram）広告の運用の知識

設計・入稿前の点検・運用チューニングで使う設定項目と目安。数値の目安は、著者の運用での目安と、執筆時点の媒体の案内にもとづく。
媒体の仕様と推奨値は変わるので、使う前に Meta の公式のヘルプ・広告ガイドで確かめる。案件の数値はここに書かない。

## 構造と目的

- 階層: 広告アカウント → キャンペーン（目的 / 予算の上限）→ 広告セット（配信期間・配信先・配置・最適化）→ 広告（クリエイティブと遷移先）
- 目的は API では `OUTCOME_AWARENESS` / `OUTCOME_TRAFFIC` / `OUTCOME_ENGAGEMENT` / `OUTCOME_LEADS` / `OUTCOME_APP_PROMOTION` /
  `OUTCOME_SALES` のような語で渡す。
- 入札戦略は、上限を付けない設定（成果の数の最大化）から始めるのが基本。目標の単価を指定する設定は、成果がたまってから。
- 1 日の予算は、日によって設定額を超えて消化されることがある。1 日だけを見て判断しない。
- 成果を数える期間（アトリビューション）は、クリックから 7 日を基本にする。どの設定で計測しているかをレポートの明細に書く。

## オーディエンス

| 種類 | 説明 |
|---|---|
| コアオーディエンス | 地域（半径で指定できる）・年齢・性別などの属性、興味・関心・行動で設定する |
| カスタムオーディエンス | サイト訪問者や自社の顧客データ（ハッシュ化してアップロード）と媒体のデータを照合する |
| 類似オーディエンス | 自社のオーディエンスに似た利用者の層。最初は類似度の最も近い設定（1%）から作る。元になるリストは最低 100 人 |

- 配信先の人数は、少なすぎると配信されにくく、広すぎると成果につながりにくい（著者の運用の目安は下限 1,500〜上限 40 万程度）。
- 広告セットどうしの重複は、管理画面の「オーディエンスの重複を表示」で確かめる（著者の運用の目安は 30% 以下）。
- 来店の促進は、カスタムオーディエンスと店舗周辺のコアオーディエンスの併用が合う。成果済みの利用者の除外を忘れない。

## クリエイティブの要件（目安）

| 形式 | 比率 / 解像度 | テキストの目安 |
|---|---|---|
| 画像（JPG / PNG） | 1.91:1〜1:1、1080×1080px 以上 | メイン 125 字、見出し 27 字、説明 27 字 |
| 動画（MP4 / MOV / GIF） | 1:1 または 4:5（縦型の配置は 9:16）、1080×1080px 以上 | 同上 |
| カルーセル（カード 2〜10 枚） | 1:1、1080×1080px 以上 | 同上（遷移先 URL は必須） |

- 動画は冒頭 3 秒で最も伝えたい部分を見せ、音なしでも伝わるようにテキストとキャプションを使う。
- 1 つの広告セットに入れる本数は多すぎないようにする（著者の運用の目安は 3〜6 本）。
- 同じクリエイティブを配信し続けると、見慣れられて反応が落ちる（著者の運用の目安は月 1〜2 回の差し替え）。
  差し替えは新しいクリエイティブと新しい広告を作って行い、大きな編集にあたる。

## 入稿前チェックリスト

- [ ] キャンペーンの名前と目的が正しく、状態が停止になっている
- [ ] 予算の額・置き場所（キャンペーン側か広告セット側の一方だけ）・入札が意図どおり
- [ ] 配信先の人数が狭すぎず広すぎない。他の広告セットとの重複が大きくない
- [ ] 配置が自動配置になっている（手動にする理由があるなら書く）
- [ ] クリエイティブが形式ごとの要件を満たしている。素材が実写か生成画像かを確かめた
- [ ] ドメイン認証が完了し、ドメインとピクセルが正しくひも付いている。ピクセルが実際に発火する
- [ ] 遷移先 URL が正しく、広告の言葉と遷移先の最初の画面の言葉が合っている
- [ ] 広告文・画像が広告ポリシー（禁止・制限されるコンテンツ）に当たらない

## 審査と学習期間

- よくある審査落ちの理由: 画像に禁止されるコンテンツを含む / 個人の属性を言い当てる表現 / 制限されるコンテンツ /
  誤解を招く表現（成果の約束、使用前と使用後の比較）/ 表記の誤り。
- 原因を特定せずに何度も再入稿しない（広告アカウントの制限につながるおそれ）。
- 学習が進む目安は、1 つの広告セットあたり 1 週間に約 50 件の成果（媒体の案内にもとづく目安。公式のヘルプで確かめる）。
- 成果が少ないときは、手前の行動（カート、フォームを開いた、など）を最適化の対象にし、広告セットをまとめて成果を 1 か所に集める。
- 広告セットが複数あるときは、キャンペーン予算で媒体に配分を任せる。増額は少しずつ行う。
