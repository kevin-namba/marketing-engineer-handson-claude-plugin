# 企業調査の出力テンプレート

該当しない節は消さずに「該当なし」「未取得」と書く。
「未取得」は取れなかった、「未確認」は確かめられなかった、「なし」は無いことを確かめた、の意味で使い分ける。

```markdown
# 企業調査: （会社・店舗名）
作成日: YYYY-MM-DD ｜ 調査の前提: （自社の商材 / 今回の目的）
情報源の概要: Web 検索（N クエリ）[+ CRM] [+ 利用者が貼った記録]

## 要約（3 文以内）
（どんな会社か。なぜ自社を必要とする可能性があるか。最適な切り口は何か）

## プロフィール
| 項目 | 内容 | 出典 |
|---|---|---|
| 正式名称・公式サイト | | |
| 業種・事業内容 | | |
| 規模（従業員数・店舗数）・所在地・設立 | | |

直近 90 日のニュース:
- （日付）（見出し）— （営業にとってなぜ意味があるか）（URL）
採用シグナル:
- （募集職種・件数・観測日）（URL）

## キーパーソン
- （氏名）— （役職）/ 経歴・公開されている発言（URL）/ 話のきっかけ: （1〜2 個）

## SNS と掲載の状況
| 媒体 | アカウント | フォロワー | 投稿頻度 | 直近の反応 | 評価 | 確認方法・取得日 |
|---|---|---|---|---|---|---|
| Instagram | あり / なし / 未確認 | | | | ◯ / △ / ✕ / 未確認 | |

| 掲載先（予約サイト・ポータル・口コミ） | 掲載 | 評価・口コミ数 | 出典 |
|---|---|---|---|

評価の付け方: ◯ = 運用できていて反応がある / △ = アカウントはあるが更新が止まっている /
✕ = 無いことを確かめた、または実質的に動いていない / 未確認 = 確かめられなかった

## 過去の接点（CRM を参照できたときだけ）
ステータス・確度（CRM の値をそのまま）/ 担当者・次アクション / 過去の商談（受注・失注とその理由）/ 既知の連絡先

## 評価（ここからは推測を含む。上の節に無い事実を新しく書かない）
良い兆候: （兆候と、その根拠にした上の節の事実）
懸念: （懸念と、注視する点）
商談で確かめる不明点:

## フック候補（選ばずに並べる。3 つまで）
| 種類 | 事実 | 出典 URL・取得日 |
|---|---|---|
| トリガーイベント / 共通のつながり / 相手の公開コンテンツ / 会社の取り組み / 役職から推測される課題 | | |

## 推奨アプローチ
最初に話す相手: （人物・部署と理由）
質問 3 つ: 1.（相手の状況）2.（課題）3.（意思決定の進め方）

## 情報源
- （タイトル）（URL）（取得日）
- CRM: （参照できた / 未連携のため Web のみ）
- 打ち切り: （上限に達した / 新しい情報が出なくなった。見ていない範囲）
```
