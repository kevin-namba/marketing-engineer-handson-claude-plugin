# 見込み客の企業調査

営業のために相手の会社を調べる。揃えるのは「何を伝えれば会ってもらえるか」の材料（書き出しに使える事実と出典）と、
「会ったときに何を聞くか」の 2 つ。どの事実を書き出しに使うかは、この Skill では選ばない。

## 最初に確定すること

- **誰が何を売るための調査か**（自社の商材・相手の業種・今回の目的）。分からなければ利用者に 1 回だけ確認する。推測で観点を決めない。
- **件数の上限**（既定: 1 社あたり Web 検索 10 クエリまで）。

## 手順

1. **公式サイトと直近 90 日のニュースを調べる**（この手順は必ず成立する）。会社名にはドメインを添えて検索する。
   抜き出すもの: 事業内容と顧客 / 規模・所在地・設立 / 直近 90 日のニュース / キーパーソン（役職・経歴・公開の発言）/ 募集中の求人。
   2 クエリ続けて新しい情報が出なければ打ち切り、見ていない範囲を「情報源」に書く。
2. **業種別の観点を足す。**

   | 相手の業種 | 追加で見る観点 |
   |---|---|
   | 店舗型ビジネス（宿泊・飲食・美容・小売・クリニック） | SNS の運用状況、予約サイトの掲載と口コミ、客層と外国人客の比率、多言語対応、採用募集 |
   | BtoB | 事業モデルと顧客セグメント、資金調達や IR、募集している職種から読む投資の領域 |
   | EC・D2C | 販売チャネル、レビューの数と評点、広告出稿の有無、定期購入の有無 |
   | 自治体・公共 | 所管の部署、年度予算と事業計画、調達の方式、議会の資料 |

   上場企業・チェーン本部・自治体のような大型の相手だけ、中期経営計画の目標と実績の差・財務の余力を足す
   （事実と仮説を分け、出典の資料名と年度を書く）。
3. **CRM を読み取り専用のツールで検索し、実体を確かめてから本文を読む**（MCP ツール → 案件表の CSV → 利用者が貼ったメモの順）。
   取り込むもの: ステータス・担当者・次アクション / 過去の受注と失注の理由 / 既知の連絡先。
   連携が無い・参照できないときは Web だけで続け、「情報源」にその旨を書く。
4. **SNS の実数は、利用者が画面で確認した記録か画面写しから読む。** Instagram と TikTok を自動で開かない（規約で禁止）。
   記録が無い項目は「未取得」、アカウントが見つからない場合は「未確認」。アカウントの有無だけは Web 検索の結果で確かめてよい。
5. **事実と評価を分けて統合する。** 一次情報（公式サイト・公式の発表・IR 資料）を優先する。
   フック候補は出典 URL 付きで 3 つまで並べ、推奨アプローチ（最初に話す相手と質問 3 つ）を書く。

**複数の会社をまとめて調べるとき**は、メインの会話で 1 社ずつ調べず、サブエージェントに分ける（1 回 5 社前後・同時に 3〜4 体まで）。
依頼文と返す形式は `references/batch-research.md`。

## 出力の型

要約（3 文以内）/ プロフィール / キーパーソン（役職・経歴・話のきっかけ）/ SNS と掲載の状況（表）/
評価（良い兆候・懸念・不明点）/ フック候補（書き出しに使える事実と出典 URL。選ばずに並べる）/
推奨アプローチ（最初に話す相手・質問 3 つ）/ 情報源

全文のテンプレートは `references/output-template.md`。節の順番は変えない。

## 守ること

- 取れなかった数値を推測で埋めない。「未取得」と書く。
- 「未確認」と「存在しない」を分ける。SNS のアカウントが見つからなくても「運用していない」と断定しない。
- 事実と評価を同じ段落に混ぜない。フック候補は選ばずに並べる（1 つに絞るのは `outreach-draft` / `outreach-copy` の側）。
- 出典は実際の URL と取得日で残す。出典 URL の無い事実はフック候補に入れない。
- CRM に書き込まない。CRM のクエリを、データの構造を推測して書かない。

## フォールバック先

- **SNS の記録が無い**: 該当欄を「未確認」とし、プロフィール画面のスクリーンショットを提供してもらう依頼を 1 回だけ出す。
- **CRM を参照できない**: Web だけで進め、「情報源」に「CRM は未連携のため Web のみ」と書く。
- **公開情報がほとんど無い**: 分かった範囲で出し、商談で聞く質問を多めに書く。
- **ページが取得できない・Web 検索が使えない**: 回避する手段を作らない。利用者が貼った本文・画面写しから作り、無い節は「未取得」と書く。
