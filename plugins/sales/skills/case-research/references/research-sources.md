# 事例調査の調査先

## 調査先の 4 種類

| 種類 | 取れるもの | 探し方 |
|---|---|---|
| 支援会社（代理店・制作会社） | 課題・施策・成果の数字が揃った導入事例 | 業種と施策名で検索し、見つけた会社の事例一覧（導入事例 / 実績 / works / case）を最後まで辿る |
| 事業会社（施策を実施した当事者） | 一次情報の数字 | プレスリリース、公式のブログ、決算資料 |
| 業界メディア・事例のまとめ | なぜその施策を選んだかという経緯 | 業界の専門メディアのインタビュー記事 |
| 広告のアーカイブ | いま配信中の広告の実物（コピー・遷移先） | 各社の広告ライブラリを人が開いて記録する |

- 広告のアーカイブでは、配信が続いている期間と同じクリエイティブの本数で成果を読む。出典は「ライブラリ名・取得日」
- 自動で取りに行ってよいのは、規約で自動収集が禁止されていない情報だけ

## 検索クエリの型

```
1. "[業界/テーマ] [施策名] 成功事例" / "[テーマ] [施策名] 事例"
2. "[業界] [施策名] 実績" / "[テーマ] プロモーション 事例 インタビュー"
3. "[支援会社名] 導入事例" / "[支援会社名] 実績"      … 支援会社を特定したあと
4. "[テーマ] キャンペーン 結果" / "[事業会社名] [施策名] 発表"  … 事業会社側の発信を拾う
5. 英語圏: "[theme] case study"
```

## 信頼度の 3 段階

| 段階 | 定義 | 例 |
|---|---|---|
| 一次情報 | 当事者の発表・原本・人が画面で確かめた実数 | 公式サイト、決算資料、事業会社のプレスリリース |
| 二次情報 | 第三者による集約・要約 | まとめ記事、支援会社の事例発表、ニュース記事 |
| 推定 | ツールの推定値、検索結果の抜粋からの読み取り | 分析ツールの推定値、スニペットの中の数字 |

優先順位は 一次 > 二次 > 推定。二次情報は一次情報で確かめてから採用し、確かめられなければ「要確認」と書く。
