## 業種ごとの定番の質問

SSOT に定番のヒアリング項目が無いときに、ここから選ぶ。

- **店舗型ビジネス**（宿泊・飲食・美容・小売・クリニック）: 来店・予約につながっている経路と SNS 運用の体制 /
  客層と外国人客の比率 / 困っているのは集客か採用か認知か / 使っている予約サイト・掲載サイト / 誰がいつ決めるか
- **BtoB**: いまその業務を誰がどう行っているか / 何がうまくいっていないか（数字で）/ なぜ今検討しているか /
  他に検討している手段・会社 / 関わる人・予算・導入の時期
- **自治体・公共**: 事業の目的と評価指標 / 所管と関係部署 / 年度の予算と調達の方式・時期 /
  過去の同種の事業と評価 / 仕様で動かせる範囲
- **定例**（既存のお客様）: 前回からの数字の変化と受け止め / うまくいっている点・いっていない点 /
  社内の新しい要望や計画 / 契約の更新についての考え
