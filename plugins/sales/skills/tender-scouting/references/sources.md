# 巡回先の選び方と検索語

## 入口の選び方

| 入口 | 使い方 |
|---|---|
| 業界の集約サイト（業界メディアのプロポーザル一覧など） | 特定の分野（観光など）の案件の起点にする |
| 都道府県・市区町村の公告一覧ページ | 発注者の一次情報。「（自治体名） 公募型プロポーザル 公告一覧」で検索して到達する。定点観測に向く |
| 観光連盟・観光協会・外郭団体のサイト | 自治体本体とは別に公募を出す。団体ごとに「お知らせ」「入札・公募」のページを見る |
| 横断検索・官公需のポータル（官公需情報ポータルサイト など） | 網羅性は高いが関係の無い案件も多い。キーワードで絞ってから公式へ進む |
| Web 検索 | 上のどこにも載っていない個別掲載を、下の検索語の型で拾う |

集約サイトに載らない目的の案件（例: 観光の一覧に載らないシティプロモーションや移住の案件）は、自治体サイトと横断検索へ切り替える。

## 検索語の型

```plain text
〇〇市 公募型プロポーザル 令和8年度 SNS
〇〇市 公募型プロポーザル 2026年度 動画制作
〇〇県 観光 プロポーザル 公告一覧
〇〇観光協会 業務委託 企画提案 募集
（目的の語） （業務の語） 公募型プロポーザル 参加者募集 <年度>
```

- 定型語: 公募型プロポーザル / 企画競争 / 企画提案 / 公告一覧 / 業務委託 / 参加者募集
- 目的の語の例: 観光誘客 / シティプロモーション / 移住・定住 / 関係人口 / 特産品
- 1 つの目的につき 5〜7 クエリを目安にし、2 クエリ続けて新しい案件が出なければ打ち切る。打ち切った範囲は出力に書く。

## 巡回のルール

- 同じサイトへの連続アクセスは間隔を空ける。失敗したときの再取得は時間を置いて 1 回だけにする。
- 自動収集を規約で禁じているサイトは巡回先に入れない（規約はサイトごとに確認する）。
- 一度当たった一覧ページは巡回先の一覧に載せ、次回の巡回の起点にする。
- リンク切れは「（名称）＋定型語」で検索し直して張り替える。

## 巡回先の一覧の形

```markdown
| 巡回先 | URL | 種類 | 対象の目的 | 追加日 | 最後に新着があった日 | 連続ゼロ回数 |
|---|---|---|---|---|---|---|
```
