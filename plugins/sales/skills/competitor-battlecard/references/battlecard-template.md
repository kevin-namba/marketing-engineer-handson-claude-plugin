# 競合ごとのカードのひな形

```markdown
### [競合の社名]（[同業 / 代替手段 / 内製 / 現状維持]）取得日 YYYY-MM-DD

**概要**: [誰に何を売っているか 1〜2 行]（出典 URL）
**打ち出し方**: [競合が自分をどう説明しているか。公式サイトの言葉で]

| 直近の動き（90 日） | 商談への影響 | 出典 |
|---|---|---|

| 競合が強い領域 | 自社の対処 |
|---|---|

| 自社が強い領域 | 根拠（利用者が渡した実績だけ） |
|---|---|

**料金**: [公式の最低料金（非公開なら「非公開」）/ 最低契約期間・初期費用 / 別料金になるもの]（一次情報 / 二次情報・要確認）

**場面別の話し方**
- 序盤に名前が出たとき: […]
- 相手がいま使っているとき: […]
- 終盤に加わったとき: […]

**想定される反論と返し方**
- 「[反論]」→ [返し方]

**相手に確かめてもらう質問**
- [質問]

**勝ち負け**: [N 件中 M 件・勝った理由・負けた理由]（社内の記録を参照できたときだけ。無ければ「未取得」）
**未確認**: [確認できなかった項目と、確かめる方法]
```

## 質問と話し方の作り方

- 質問は、競合の弱い点をこちらが指摘するのではなく、相手が競合に確かめることで分かる形にする
  （「月に何本まで含まれるかは確認されましたか」）。自社が答えられない質問は入れない。
- 序盤: 比較を避けず、相手が何を重視して比べているかを聞く
- 乗り換え: いまの取引先の良い点を先に認め、足りていない点を相手の言葉で聞く
- 終盤: 決まっている評価の軸の中で、自社が有利な点と根拠を 1 つに絞って示す
