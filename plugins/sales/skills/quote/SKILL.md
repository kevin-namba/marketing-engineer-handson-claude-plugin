# 見積書

聞くこと・計算・命名・保存先を固定して、見積書を毎回同じ形で作る。作るのは下書きのファイルまでで、相手への送付は人が内容を確認してから行う。
スクリプトの依存: Python 3 と openpyxl（`pip install openpyxl`）。PDF への変換は LibreOffice（`soffice`）。

## 発行元の情報（設定の 1 箇所）

社名・住所・登録番号・振込先・印影・既定の支払条件を 1 つの JSON に置く。見本は `references/company-info.example.json`
（`tax_rate` 税率 / `tax_rounding` 端数処理 floor・round・ceil / `valid_days` 有効期限の既定 / `number_prefix` 番号の接頭辞）。
利用者の作業フォルダ（例: `sales-config/company-info.json`）に写して使う。
`{{未設定}}` の項目は 1 回だけ聞いて設定に書き戻す。載せない項目は空文字にする（空の項目は見積書に出さない）。

## 聞くこと

すでに会話や提案の骨子に出ている項目は聞き直さない。足りないものだけを 1 回でまとめて聞く。

| 項目 | 既定 |
|---|---|
| 宛先（正式名称。部署・担当者名は任意） | なし。略称で渡されたら正式名称を確認する |
| 件名 | なし |
| 明細（品目・数量・単位・**税抜**単価） | 単位は「式」。単価は料金表か利用者の指定から |
| 有効期限 | 発行日から 30 日 |
| 発行日 | 今日 |
| 備考（納期・支払条件） | 発行元の既定の支払条件 |

## 手順

1. **明細を構造化する。** 次の形の JSON にする。税込で受け取った行には税込の印（`tax_included: true`）を立て、税の加算を飛ばす。

   ```json
   {
     "client_company": "株式会社サンプル",
     "client_name": "営業部 山田 太郎 様",
     "subject": "Web サイト制作 御見積",
     "issue_date": "2026-10-05",
     "items": [
       {"name": "初期設定", "qty": 1, "unit": "式", "unit_price": 100000},
       {"name": "交通費（実費）", "qty": 1, "unit": "式", "unit_price": 11000, "tax_included": true}
     ],
     "remarks": "納期: ご発注から 4 週間"
   }
   ```

   作る前に `--dry-run` で小計・税・合計を出し、利用者に見せて確認する。
2. **番号を採番する。** 日付＋連番（`Q-YYYYMMDD-001`）。スクリプトが台帳（保存先の親フォルダの `quote-ledger.csv`）を読み、同じ日は連番を進める。
3. **表計算ファイルを生成し、PDF に変換する。**

   ```bash
   python3 "${CLAUDE_PLUGIN_ROOT}/skills/quote/scripts/create_quote.py" \
     --company sales-config/company-info.json --data quote.json \
     --out-dir "quotes/株式会社サンプル" --pdf
   ```

4. **クライアント別のフォルダを探し、無ければ作って保存する。** アップロードは外部への書き込みなので、
   保存先のフォルダとファイル名を見せて確認を取ってから行う。
5. **報告する。** 保存先の URL（またはローカルのパス）・番号・合計（税込）・有効期限。税込の印を立てた行、同名のファイルの有無も書く。

## 出力の型

```markdown
見積書を作成した（送付はしていない）。
- 見積番号: Q-YYYYMMDD-NNN
- 宛先 / 件名: […]
- 小計（税抜）/ 消費税 / 合計（税込）: ¥… / ¥… / ¥…
- 有効期限: YYYY-MM-DD
- 保存先: [クライアント別フォルダの URL、またはローカルのパス]（xlsx / pdf）
- 確認してほしい点: [税込として扱った行 / 同名のファイル / 未設定だった発行元の項目]
```

## 守ること

- 税の計算は計算機に任せる。人が暗算した税込を明細に混ぜない。
- 単価・数量をでっち上げない。料金表に無い品目や未定の数量は聞く。値引きも利用者が指示した額だけを入れる。
- ファイル名は送付用の形に固定する（`御見積書_件名_宛先の正式名称御中_YYYYMMDD`）。
- 同名のファイルがあっても確認なしに上書きしない。新しく保存し、古いほうの扱いを人に確認する。
- 案件が複数でも 1 件ずつ作る。送付しない。

## フォールバック先

- **資料置き場に保存できない**（未連携・認証切れ）: ローカルに残し、保存先のパスと手動アップロードの手順を案内する。
- **PDF の変換環境が無い**: 表計算ファイルだけを出し、変換手段を案内する。
- **Python を実行できない**: 小計・税・合計を表で示し、明細を CSV で渡して、利用者の見積書のひな形に貼ってもらう。
