# 出展・登壇の発掘

出展・登壇の機会を探し、適合度の理由を付けて一覧にし、本命の応募・打診の提案書まで作る。申し込みと送信は人が行う。

## 先に確定する

目的（リード獲得 / 認知 / 採用 のどれか 1 つ）/ 持ちネタ（話せる実績・データ。数字には検証の状態を付ける）/
対象の聴衆（業界・職種・地域）/ 条件（期間・予算の上限・出られる人）。
足りない項目は 1 回でまとめて聞く。決まっていなければ探し始めない。

## 手順

1. **4 種類を当たる**（依頼に無ければ、種類ごとに 5 件まで・合計 15 件まで）。

   | 種類 | 見つけ方 |
   |---|---|
   | 展示会・商談会 | 業界名と「展示会」で検索する。会場の年間予定と、前回の出展社一覧を見る |
   | カンファレンスの登壇 | 業界名と「登壇者募集」「Call for Speakers」で検索する。過去回の登壇者と演題を見る |
   | ポッドキャスト・動画の対談 | 業界のテーマを扱う番組を探し、ゲスト回がある番組に絞る |
   | 自治体・商工会のセミナー | 商圏の自治体名と「セミナー」「講師」で検索する |

2. **開催実績・締切・費用は公式サイトで確認する。** 次回の日程・窓口（公開されているもの）・確認した URL と取得日も記録する。
   確認できない項目は「未確認」と書く（締切をでっち上げない）。
3. **適合度はスコアではなく理由の行で付ける**（聴衆の一致 / 持ちネタとの噛み合い / 時期と工数）。
   最後に「本命 / 候補 / 見送り」を付け、見送りにも理由を書く。
4. **今期の締切に間に合わないものは捨てず、「来期の候補」の一覧に分ける**（いつ頃から準備を始めるかを添える）。
5. **登壇提案は聴衆の得で演題を書く**（自社紹介にしない）。持ち帰る 3 点と、回収の一手を必ず入れる。
   出展の場合は、目的と目標・展示する内容・当日の体制・費用・終了後の追客の手順を書く。

```
演題: 月曜から使える、予約サイトに頼らない集客の 3 ステップ
概要: 客室 30 室の温泉旅館が、Instagram の運用で平日の直接予約を
      増やした手順を、準備・投稿・計測の 3 段階で紹介します。
聴衆が持ち帰るもの:
  1. 投稿の企画を 1 か月分まとめて決めるための表
  2. 直接予約を計測するためのリンクの付け方
  3. 最初の 3 か月で計測する数字と、計測しなくてよい数字
話者の根拠: 宿泊施設の SNS 運用を 5 年担当（実績の数字は検証状態を付けて記載する）
回収の一手: 名刺を交換した参加者に資料を送り、講演の内容を自社ブログの記事にする
```

## 出力の型

```markdown
# 出展・登壇の機会: [業界 / 目的]（YYYY-MM-DD）
目的: [リード / 認知 / 採用]　持ちネタ: […]　当たった範囲: [種類と件数。当たらなかった種類]

## 今期の候補
| 機会 | 種類 | 日程 | 締切 | 費用 | 適合度の理由（聴衆 / 持ちネタ / 時期と工数） | 判定 | 窓口 | 確認した URL（取得日） |

## 来期の候補
| 機会 | 前回の締切・日程 | 準備を始める時期 | 理由 |

## 登壇提案書（本命）
## 打診の文面（送信はしていない）
## 未確認の項目と、人が行うこと
```

## 守ること

- 聴衆は規模より一致を優先する。
- 主催者の窓口は公開されているものだけを記録する。公開されていない個人の連絡先を推測したり集めたりしない。
- 話者の根拠の数字は、利用者が渡した実績だけを使う。
- 応募・送信はしない。打診の文面には「なぜこのイベントか」を 1 行入れ、一斉送信の文面は作らない。

## フォールバック先

- **適合する機会が薄い**: 自主開催（ウェビナー・共催）の企画と、探し方の指示書（どの検索語で、どのページを、どの時期に見るか）に切り替える。
- **Web 検索が使えない**: 利用者が持っているイベントの URL・案内を受け取り、手順 2〜5 を行う。
- **公式サイトに情報が無い**: 「未確認」とし、主催者の公開窓口に問い合わせる文面の下書きを添える（送信は人）。
